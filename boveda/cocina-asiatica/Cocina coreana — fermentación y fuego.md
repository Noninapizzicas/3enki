# Cocina coreana — fermentación y fuego

Corea construye su cocina sobre fermentación (kimchi, doenjang, gochujang) y fuego (BBQ, jjigae). Cada comida es un ecosistema de banchan (acompañamientos) alrededor de un plato central.

## Los jang — las 3 pastas fermentadas

| Jang | Ingrediente | Perfil | Uso |
|---|---|---|---|
| **Gochujang** (고추장) | Chile + arroz glutinoso + meju (soja fermentada) | Picante-dulce-umami | Bibimbap, marinadas, tteokbokki |
| **Doenjang** (된장) | Pasta de soja fermentada | Umami profundo, terroso | Jjigae (guiso), aliños |
| **Ganjang** (간장) | Salsa de soja coreana | Salada-umami | Todo — marinadas, sopas, dips |

## Kimchi — patrimonio fermentado

```
200+ tipos de kimchi. El clásico (baechu kimchi):

  1. Col napa en cuartos, salar con sal gruesa (2-4h)
  2. Lavar y escurrir
  3. Pasta: gochugaru + fish sauce + salsa de gamba + ajo + jengibre + azúcar
  4. Rellenar cada hoja con pasta
  5. Prensa en tarro (anaeróbico)
  6. Fermentar: 1-2 días ambiente → nevera

  Joven (1 semana): fresco, crujiente
  Maduro (1-3 meses): ácido, complejo — ideal para jjigae
  Viejo (6+ meses): muy ácido — para kimchi jjigae y kimchi fried rice
```

| Tipo de kimchi | Ingrediente base | Nota |
|---|---|---|
| **Baechu** | Col napa | El clásico — 80% del kimchi |
| **Kkakdugi** | Rábano en cubos | Crujiente, fresco |
| **Oi sobagi** | Pepino relleno | Verano |
| **Dongchimi** | Rábano en agua | Kimchi acuoso, invernal |
| **Yeolmu** | Rábano joven | Verano, ligero |

## Korean BBQ (고기구이)

| Corte | Marinada | Acompañamiento |
|---|---|---|
| **Samgyeopsal** (삼겹살) | Sin marinar (panza de cerdo) | Ssamjang, ajo, lechuga |
| **Bulgogi** (불고기) | Soja + pera + sésamo + ajo | Arroz, banchan |
| **Galbi** (갈비) | Soja + pera + azúcar + ajo | Igual — costillas marinadas |
| **Dak galbi** (닭갈비) | Gochujang + verduras | Servido en sartén |

### Ssam — el ritual de envolver

```
Hoja de lechuga (o perilla)
  + slice de carne BBQ
  + arroz (poco)
  + ajo crudo (lámina)
  + ssamjang (doenjang + gochujang + ajo + sésamo)
  + kimchi
  → envolver → comer de un bocado
```

## Platos fundamentales

| Plato | Tipo | Descripción |
|---|---|---|
| **Bibimbap** | Arroz | Arroz + verduras + huevo + gochujang (mezclar) |
| **Japchae** | Fideos | Fideos de boniato salteados + verduras + sésamo |
| **Tteokbokki** | Street food | Pasteles de arroz en salsa gochujang |
| **Sundubu jjigae** | Guiso | Tofu suave + gochugaru + mariscos |
| **Kimchi jjigae** | Guiso | Kimchi viejo + cerdo + tofu |
| **Doenjang jjigae** | Guiso | Pasta de soja + verduras + tofu |
| **Samgyetang** | Sopa | Pollo relleno de arroz + ginseng |
| **Pajeon** | Tortilla | Cebolleta + mariscos, con masa |

## Banchan — los acompañamientos

Cada comida coreana incluye 3-12+ banchan gratuitos que se reponen:

| Banchan | Ingrediente | Tipo |
|---|---|---|
| **Kimchi** | Col napa | Siempre presente |
| **Kongnamul** | Brotes de soja | Salteados con sésamo |
| **Sigeumchi** | Espinaca | Blanqueada, sésamo, soja |
| **Myeolchi** | Anchoas secas | Salteadas con sirope |
| **Gyeran mari** | Tortilla enrollada | Con cebolleta |

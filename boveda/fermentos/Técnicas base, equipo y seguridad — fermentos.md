# Técnicas base, equipo y seguridad — fermentos

## Equipo esencial

```
RECIPIENTES:
  Tarros de vidrio de boca ancha (mason jars): el estándar universal
    → Ball, Kilner, Weck, o cualquier tarro de conserva con boca ancha
    → Tamaños útiles: 500ml, 1L, 2L, 5L
    → Ventaja: visibilidad total del proceso, no reaccionan con el ácido
  
  Tarros de cerámica o gres (fermentadores de piedra):
    → Tradicionales para chucrut y kimchi a gran escala
    → Con ranura de agua para crear sello anaeróbico natural
    → Más caros (20-80€) pero excelentes para producción regular
  
  Garrafas de vidrio (para vino, vinagre, kombucha en cantidad):
    → 5L, 10L, 23L · con airlocks de goma

  EVITAR:
    Metal sin revestimiento (la sal y el ácido lo atacan)
    Plástico ordinario (absorbe olores y puede migrar plastificantes)
    Plástico alimentario (código ♳ PET o ♵ PP) sí es seguro para uso temporal

AIRLOCKS Y SELLOS:
  Airlock tipo S (el más común): llena con agua o vodka · permite salida de CO₂ sin entrada de aire
  Airlock de burbujeo: similar · para garrafas de fermentación alcohólica
  Sello de agua cerámico (para tarros de piedra): agua en la ranura del borde
  
  Alternativas DIY para lactofermentación:
    Paño de tela tupida + goma elástica → permite ventilación, evita insectos
    Tapa de silicona con válvula unidireccional → mejor que el paño
    Bolsa de plástico con agua + sal (peso) sobre la superficie del fermento

PESOS Y MANTENEDORES DE SUMERSIÓN:
  Las verduras DEBEN estar sumergidas bajo la salmuera → el oxígeno es el enemigo
  → Pesos de fermentación de vidrio o cerámica (5-10€ en Amazon)
  → Bolsa de plástico rellena con salmuera (misma concentración que el fermento) como peso
  → Hoja de col o repollo plegada sobre la verdura como barrera
  → Piedra limpia envuelta en film alimentario

HERRAMIENTAS DE MEDICIÓN:
  Termómetro de sonda: indispensable para fermentos que necesitan temperatura controlada
  pHmetro o papel pH: para verificar seguridad y avance de la fermentación
    → pH < 4.6 = zona segura para encurtidos y lactofermentos
    → Papel pH (1-4€) suficiente para uso básico · pHmetro (15-40€) más preciso
  Refractómetro (para fermentos alcohólicos): mide Brix (concentración de azúcar)
  Densímetro/hidrómetro: mide la densidad del mosto → calcula el alcohol
  Termómetro de infrarrojos: cómodo para medir sin introducir en el líquido

EMBOTELLADO Y ALMACENAJE:
  Botellas de vidrio con tapón mecánico (Grolsch, Bormioli): para F2 de kombucha y kéfir de agua
  Botellas de PET recicladas (de bebida): para F2 · la deformación de la botella indica la presión
    → Aprieta la botella: si está dura como una roca → lista / refrigerar · si está blanda → seguir
  Cápsulas corona + taponador: para cerveza y sidra · económico y efectivo
  Botellas de cerámica o vidrio oscuro: para vinagres (protegen de la luz)
```

## Higiene y esterilización

```
EL PRINCIPIO: no eliminar todo (matamos lo bueno también) sino DESFAVORECER los patógenos
  y FAVORECER los microorganismos que queremos.

PARA LACTOFERMENTACIÓN (sal + verdura):
  → Lavar bien las verduras con agua · no es necesario esterilizar · la sal hace el trabajo
  → Lavar los tarros con agua caliente y jabón · aclarar bien
  → Manos limpias (sin jabón antibacteriano antes de tocar los gránulos o el fermento)

PARA FERMENTOS ALCOHÓLICOS (vino, cerveza, sidra):
  → La esterilización ES CRÍTICA · la higiene inadecuada arruina el lote
  → Solución de metabisulfito potásico (Campden): 1 cucharadita en 4L agua · enjuagar todo
  → Star San (sanitizante sin enjuague): 1.5ml/L agua · contacto 30s · no hace falta aclarar
    (espuma no es problema — "Don't fear the foam")
  → Alternativa: solución de lejía diluida (5ml lejía / 4L agua) · ACLARAR muy bien después

PARA KOJI, TEMPEH Y NATTO:
  → Esterilización estricta del equipo de cocción y manipulación
  → Las esporas de Bacillus (natto) son muy resistentes → cocer la soja bien tapada para evitar
    contaminación del resto de fermentos en la cocina

REGLA PRÁCTICA:
  → Cuanto más alcohol habrá en el fermento → menos crítica la esterilización inicial (el alcohol
    que se produce mata los patógenos durante el proceso)
  → Sin alcohol (lactofermentación, vinagre, kombucha) → la sal o el pH hacen el trabajo
  → Sin sal Y sin alcohol → la esterilización es fundamental (natto, tempeh)
```

## Control de temperatura

```
OPCIONES DE INCUBACIÓN CALIENTE (para tempeh, natto, yogur):

  DIY con caja térmica:
    Caja de poliestireno o nevera portátil · botella de agua caliente (60-70°C) en la base
    Termómetro dentro · cambiar el agua cada 6-8h si la temperatura baja
    → Económico y funcional para lotes esporádicos

  Yogurtera eléctrica:
    Modelos con control de temperatura (15-70°C): Instant Pot / SousVide Precision
    → 25-50€ · la más versátil para todos los fermentos cálidos

  Deshidratador de alimentos con ajuste de temperatura:
    → Convierte en incubadora perfecta · además de su uso principal
    → 40-80€ · muy recomendado si se va a hacer tempeh o natto con regularidad

  Horno con la luz encendida:
    → Genera ~25-30°C sin encender la resistencia · útil para fermentos mesofílicos
    → Para tempeh/natto (30-42°C): el horno convencional no mantiene bien la temperatura

  Caja con bombilla de 25W:
    → DIY básico · con termostato analógico o digital (5-15€) para control preciso
    → Capacidad ilimitada según el tamaño de la caja

FRÍO CONTROLADO (para fermentos lentos: chucrut largo, miso, vinagre):
  Bodega, sótano, garaje fresco → 12-18°C = ideal
  Si no se tiene: buscar el rincón más fresco de la casa (suelo de la despensa, etc.)
  La nevera de encurtidos/lácteos ya los frena suficientemente para el almacenaje largo
```

## Salmuera — proporciones y preparación

```
LA SALMUERA ES LA BASE DE LA LACTOFERMENTACIÓN. Proporciones en peso (g sal / L agua):

SALMUERA LIGERA (1.5-2%): 15-20g sal/L
  → Fermentación rápida (3-5 días) · sabor más suave · mayor riesgo de kahm yeast
  → Para: encurtidos de verano, verduras de consumo rápido

SALMUERA ESTÁNDAR (2-3%): 20-30g sal/L   ← EL RANGO UNIVERSAL
  → Equilibrio perfecto entre velocidad y seguridad · el punto de partida para todo
  → Para: pepinillos, zanahoria, coliflor, remolacha, kvass de remolacha

SALMUERA FUERTE (3-5%): 30-50g sal/L
  → Fermentación lenta · sabor más salado · más estable para almacenaje largo
  → Para: ajos enteros, fermentos de almacenaje largo (> 3 meses)

CONSERVACIÓN EN SALMUERA (> 5%): > 50g sal/L
  → Inhibe también las BAL · no es fermentación activa · es conservación pura
  → Para: alcaparras, aceitunas crudas, anchoas

AGUA PARA SALMUERA:
  → EVITAR agua del grifo con cloro (inhibe las BAL)
  → Opciones: agua mineral embotellada · agua filtrada · agua hervida y enfriada
  → El agua de pozo (sin cloro) funciona perfectamente

SAL:
  → SAL SIN YODO (el yodo inhibe las BAL)
  → SAL SIN ANTIAGLOMERANTES (algunos inhiben la fermentación)
  → Válidas: sal marina gruesa, sal de roca, flor de sal, sal kosher
  → Evitar: sal de mesa yodada, sal con flúor
```

## Kahm yeast vs moho real — la distinción clave

```
KAHM YEAST (levadura Kahm):
  QUÉ ES: película blanca, crema o ligeramente amarillenta · PLANA · MATE · sin pelusa
  OLOR: suave, levadoso, no desagradable
  SEGURIDAD: INOFENSIVA · el fermento bajo ella es seguro
  CAUSA: exceso de azúcar en el fermento · temperatura alta · salmuera demasiado ligera
  
  ACCIÓN: raspar/retirar la película con cuchara limpia · comprimir la verdura para que
          quede más sumergida · si vuelve mucho, el fermento tiene demasiada fructosa

MOHO REAL (el peligroso):
  QUÉ ES: peluda (fuzzy), con volumen, con color → NEGRO, VERDE, AZUL, ROSA, NARANJA
  OLOR: desagradable, a putrefacto o a moho húmedo
  SEGURIDAD: DESECHAR el lote completo — no basta con retirar la parte superior
  CAUSA: anaerobiosis insuficiente (verdura no sumergida) · poca sal · contaminación

REGLA PRÁCTICA:
  ¿Tiene pelusa con color? → Desechar sin duda
  ¿Es plano, blanco/crema y huele normal? → Kahm, quitar y continuar
  ¿Tienes dudas? → Oler: ácido normal = bien · putrefacto = desechar
```

# Volatilidad implícita (IV)

Cuánto **espera** el mercado que se mueva el subyacente. Sube antes de earnings / datos macro → **encarece las primas** (mayor probabilidad de movimiento grande). Cae tras el evento (*IV crush*). Afecta el valor extrínseco vía [[Las griegas|vega]].

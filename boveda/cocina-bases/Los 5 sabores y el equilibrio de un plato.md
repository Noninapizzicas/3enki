# Los 5 sabores y el equilibrio de un plato

Un gran plato no depende de un solo sabor dominante sino del equilibrio entre los cinco sabores básicos. Cada cocina del mundo ha encontrado su propio punto de equilibrio.

## Los 5 sabores básicos

| Sabor | Receptor | Fuentes principales | Función en el plato |
|---|---|---|---|
| **Dulce** | Receptores T1R2/T1R3 | Azúcar, miel, frutas, mirin | Suaviza, redondea, contrarresta amargo |
| **Salado** | Canales ENaC | Sal, soja, fish sauce, queso | Amplifica todos los demás sabores |
| **Ácido** | Receptores PKD2L1 | Limón, vinagre, tomate, vino | Corta grasa, refresca, despierta |
| **Amargo** | Receptores T2R (25 tipos) | Café, cacao, endivias, cerveza | Complejidad, contraste |
| **Umami** | Receptores mGluR4 | Glutamato: parmesano, soja, tomate seco, setas, alga | Profundidad, "deliciosidad" |

## Umami — el quinto sabor

Identificado por Kikunae Ikeda (1908), el umami es el sabor del glutamato libre y los nucleótidos (inosinato, guanilato).

### Sinergia umami

```
Glutamato (vegetal) + Inosinato (animal) = umami × 8

Ejemplos clásicos:
  - Kombu + katsuobushi = dashi (Japón)
  - Tomate + parmesano = pasta italiana
  - Sofrito + jamón = cocina española
  - Cebolla + carne = fondo universal
```

## Equilibrio por cocina

| Cocina | Eje dominante | Equilibrio típico |
|---|---|---|
| **Francesa** | Umami + grasa | Fondo + mantequilla + vino (ácido sutil) |
| **Tailandesa** | Los 5 en cada plato | Dulce (azúcar palma) + salado (fish sauce) + ácido (lima) + picante + umami |
| **Japonesa** | Umami puro | Dashi + soja + mirin (dulce) — simplicidad |
| **Mexicana** | Picante + ácido + umami | Chile + limón + tomate — capas de complejidad |
| **India** | Aromático + picante + dulce | Especias + chile + mango/tamarindo |
| **Italiana** | Umami + ácido | Parmesano + tomate + aceite de oliva |
| **Española** | Umami + sal + grasa | Jamón + aceite de oliva + pimentón |

## Corrección de sabores

| Problema | Corrección |
|---|---|
| **Muy salado** | Añadir ácido (limón), dulce (azúcar), volumen (más ingrediente) |
| **Soso** | Sal + ácido primero, luego umami si falta profundidad |
| **Muy ácido** | Grasa (mantequilla, aceite) + dulce |
| **Muy dulce** | Ácido (vinagre, cítrico) + sal |
| **Amargo** | Sal + grasa + dulce |
| **Plano (sin vida)** | Ácido (unas gotas de limón al final) — el truco universal |

## Más allá de los 5: sensaciones

| Sensación | Fuente | No es un sabor, es... |
|---|---|---|
| **Picante** | Capsaicina (chile), piperina (pimienta) | Dolor (receptor TRPV1) |
| **Astringente** | Taninos (vino, té) | Sequedad (precipita proteínas) |
| **Graso** | Ácidos grasos | Candidato a 6º sabor (oleogustus) |
| **Fresco** | Mentol (menta) | Frío (receptor TRPM8) |
| **Metálico** | Hierro, sangre | Iones metálicos |

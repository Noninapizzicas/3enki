# Awesome Raspberry Pi — Referencia curada RPi

Lista curada principal de herramientas, proyectos, imágenes y recursos para todas las variantes de Raspberry Pi. 15.8k estrellas en GitHub.

## Modelos

Desde el Pi 1 original (2012) hasta Pi 500+ (sep 2025), incluyendo variantes Pico (RP2040/RP2350).

# Cocina turca — puente entre mundos

Turquía es el puente literal entre Mediterráneo y Asia. Su cocina absorbe lo mejor de ambos mundos: la despensa mediterránea + las especias y técnicas de Asia Central y Persia.

## Pilares de la cocina turca

| Pilar | Ejemplo |
|---|---|
| **Pan** | Pide, simit, lavash, bazlama — pan en cada comida |
| **Yogur** | Ayran, cacık, con carne, con arroz — ubicuo |
| **Carne** | Cordero dominante, ternera, pollo — cerdo ausente |
| **Especias** | Pul biber (chile aleppo), comino, sumac, pimentón |
| **Verduras** | Berenjena (reina), tomate, pimiento, pepino |
| **Legumbres** | Lentejas (rojas y verdes), garbanzos |
| **Aceite de oliva** | Costa egea y mediterránea |
| **Mantequilla** | Interior de Anatolia — clarificada para cocinar |

## Kebabs — más allá del döner

| Kebab | Forma | Carne | Cocción | Origen |
|---|---|---|---|---|
| **Döner** | Espetón vertical, láminas | Cordero/ternera | Rotativo vertical | Universal |
| **Şiş** | Brocheta | Cordero marinado | Brasa | Clásico |
| **Adana** | Largo en espada (sin brocheta) | Cordero picado, pul biber | Brasa | Adana |
| **İskender** | Döner sobre pan + tomate + yogur | Cordero | Brasa + salsa | Bursa |
| **Beyti** | Rollito envuelto en lavash | Cordero picado | Horno | Estambul |
| **Testi** | En olla de barro sellada (se rompe al servir) | Cordero + verduras | Horno lento | Capadocia |
| **Çöp şiş** | Mini brochetas rápidas | Cordero en dados | Brasa intensa | Esmirna |

## Meze turco

| Meze | Ingrediente | Tipo |
|---|---|---|
| **Hummus** | Garbanzos + tahini | Dip frío |
| **Cacık** | Yogur + pepino + ajo + menta | Dip frío (versión turca del tzatziki) |
| **Babaganoush** | Berenjena ahumada + tahini | Dip ahumado |
| **Acılı ezme** | Tomate + chile + cebolla | Salsa picante |
| **Sigara böreği** | Phyllo + feta enrollado frito | Caliente |
| **Patlıcan kızartma** | Berenjena frita + yogur | Caliente/frío |
| **Çiğ köfte** | Bulgur + pasta de tomate + especias | Crudo (vegano moderno) |
| **Yaprak sarma** | Hojas de parra + arroz + piñones | Frío |

## Desayuno turco (kahvaltı)

```
El desayuno turco es una de las comidas más elaboradas del mundo:

Mesa típica:
  - Quesos: beyaz peynir (feta), kaşar, lor
  - Aceitunas (verdes y negras)
  - Tomate + pepino + pimiento
  - Miel + kaymak (nata espesa)
  - Mermeladas caseras (cereza, rosa, higo)
  - Huevos: menemen (revueltos con tomate y pimiento)
  - Pan: simit, pide caliente
  - Çay (té negro) — interminable
```

| Dulce | Masa | Relleno | Almíbar |
|---|---|---|---|
| **Baklava** | Phyllo (40+ capas) | Pistacho (Gaziantep) o nuez | Almíbar + agua de rosa |
| **Künefe** | Kadayıf (cabello de ángel) | Queso fundido | Almíbar |
| **Tulumba** | Masa frita acanalada | Hueca | Almíbar frío |

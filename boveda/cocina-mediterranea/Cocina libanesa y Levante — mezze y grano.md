# Cocina libanesa y Levante — mezze y grano

El Levante (Líbano, Siria, Palestina, Jordania) comparte una cocina de grano, legumbre y mezze que ha conquistado el mundo. Líbano es su embajador más visible.

## Ingredientes definitorios

| Ingrediente | Rol | Nota |
|---|---|---|
| **Tahini** | Pasta de sésamo | Base de hummus, salsas, aliños |
| **Bulgur** | Trigo partido | Kibbeh, tabbouleh, pilaf |
| **Garbanzos** | Legumbre reina | Hummus, falafel, estofados |
| **Za'atar** | Mezcla: tomillo + sésamo + sumac | Sobre pan con aceite, sobre todo |
| **Sumac** | Ácido-afrutado (polvo rojo) | Ensaladas, carnes, fattoush |
| **Melaza de granada** | Dulce-ácido espeso | Aliños, marinadas, muhammara |
| **Aceite de oliva** | Grasa principal | Siria produce excelente AOVE |
| **Pan pita/khubz** | Pan plano | Acompaña todo, es cuchara |

## Mezze — el corazón de la mesa

| Mezze | Ingredientes | Tipo |
|---|---|---|
| **Hummus** | Garbanzos, tahini, limón, ajo | Dip frío |
| **Baba ganoush** | Berenjena asada, tahini, limón | Dip ahumado |
| **Muhammara** | Pimiento rojo, nuez, melaza granada | Dip picante-dulce |
| **Labneh** | Yogur colado (queso) | Untable, con aceite y za'atar |
| **Fattoush** | Ensalada + pan frito + sumac | Ensalada |
| **Tabbouleh** | Perejil (mucho), bulgur (poco), tomate, limón | Ensalada verde |
| **Kibbeh** | Bulgur + cordero + piñones | Frito/crudo/horno |
| **Falafel** | Garbanzos crudos + hierbas + especias | Frito |
| **Shanklish** | Queso fermentado con tomillo | Desmenuzado |
| **Warak enab** | Hojas de parra + arroz + carne | Enrollado |

## Hummus — la receta definitiva

```
Ingredientes (para ~4 personas):
  - 250g garbanzos secos (remojo 12-24h + bicarbonato)
  - 80g tahini de calidad
  - Zumo de 1.5 limones
  - 1 diente de ajo
  - 60ml agua helada de cocción
  - Sal
  - Comino (opcional, 1/2 cucharadita)

Secreto:
  1. Cocer garbanzos MUCHO (hasta que se deshagan, ~1.5h, con bicarbonato)
  2. Pelar garbanzos (opcional pero transforma la textura)
  3. Procesador: tahini + limón + ajo PRIMERO (2min)
  4. Añadir garbanzos calientes + agua helada
  5. Procesar 5 minutos sin parar → cremosidad sedosa
  6. Servir: pozo en centro, aceite de oliva, pimentón, garbanzos enteros
```

## Falafel — los no-negociables

```
GARBANZOS CRUDOS (remojados, NO cocidos — si usas enlatados, se deshace)

Garbanzos crudos remojados + cebolla + perejil + cilantro + comino + ajo
→ procesar (textura gruesa, NO puré)
→ reposar 1h en frío (para que compacte)
→ formar bolas/discos
→ freír en aceite a 180°C hasta dorado crujiente

Se sirve en pita con tahini, pickles, verduras
```

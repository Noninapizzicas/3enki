# Destilación y extracción — aceites esenciales, hidrolatos

## Principios de separación por volatilidad

```
La destilación separa componentes de una mezcla aprovechando sus diferente presión de vapor.

LEY DE RAOULT (mezclas ideales):
  P_total = Σ(x_i × P°_i)
  x_i = fracción molar del componente i
  P°_i = presión de vapor del componente puro

  El componente más volátil (P° mayor → T_eb menor) se enriquece en el vapor

PUNTOS DE EBULLICIÓN relevantes:
  Agua          100°C   (1 atm)
  Etanol         78.4°C
  Acetona        56.1°C
  Limoneno      176°C   (terpeno del limón)
  Linalool      198°C   (terpeno de lavanda)
  Mentol        212°C   (menta)
  Eugenol       253°C   (clavo)
```

## Hidrodestilación — aceites esenciales caseros

```
PRINCIPIO: destilación con arrastre de vapor de agua
  Los aceites esenciales (P°_baja) se co-destilan con el vapor de agua mucho antes
  de su punto de ebullición real (> 150°C).
  El vapor entra a 100°C → arrastra los compuestos volátiles → condensan juntos

MONTAJE BÁSICO DIY:
  Olla a presión modificada → serpentín de cobre (tubo Cu 6mm, 3m enrollado en espiral)
               ↓ vapor                    ↓ enfriamiento (agua fría que circula)
  Material vegetal + agua                  → condensado: agua + AE
                                           Florentino (separador)
                                           → AE flota si ρ < 1 (la mayoría)
                                           → AE hunde si ρ > 1 (clavo, canela)

FLORENTINO (esenciero):
  Recipiente cónico con tubo de drenaje a la mitad de la altura
  El hidrolato (agua) rebosa por el tubo → el AE queda en la superficie → se acumula
  DIY: botella de laboratorio Erlenmeyer con tubo en T lateral o separador de uso laboratorio

MATERIALES Y RENDIMIENTOS ORIENTATIVOS:
  Lavanda (flores): 1 kg → 7-15 ml de AE  (0.7-1.5%)
  Rosa (pétalos):   1 kg → 1-3 ml de AE   (muy bajo → las rosas destiladas son caras)
  Romero:           1 kg → 10-20 ml de AE
  Eucalipto:        1 kg → 15-30 ml de AE
  Menta piperita:   1 kg → 10-25 ml de AE
  Lavanda + agua:   1 kg planta → 500-800 ml de hidrolato (todo lo que no es AE)

HIDROLATO (agua floral):
  El agua de destilación que queda → contiene compuestos hidrosolubles del aceite esencial
  Hidrolato de lavanda → agua floral para tónicos, sprays, cosmética
  pH: 4.5-6 (ligeramente ácido → conservante natural)
  Conservación: 6-12 meses refrigerado o con conservante (Optiphen 0.5%)
```

### Destilador de menta paso a paso

```
MATERIAL: 200g de hojas de menta fresca (Mentha × piperita, no spearmint)
AGUA: 1.5L en la olla
TEMPERATURA: a fuego medio-alto → mantener vapor constante sin hervir a borbotones

DURACIÓN: 45-60 min de destilación
COLECTAR: los primeros 150ml son los más ricos en AE → llamados "primera fracción"
  (los componentes más volátiles salen primero)

DECANTACIÓN:
  Dejar reposar 1h → el AE sube → recoger con pipeta Pasteur
  Volumen esperado: 0.5-2ml de AE puro (mentol + mentona + isomentol)
  El resto: 150ml de hidrolato de menta (usa en bebidas, sprays)

ANÁLISIS (opcional):
  Cromatografía de gases (no casera) → identifica los componentes exactos
  Test de olfato comparado con AE comercial → comparar notas (top/middle/base)
```

## Extracción con disolvente

```
PRINCIPIO: "lo similar disuelve lo similar"
  Compuestos polares (ácidos, alcoholes) → disolventes polares (agua, etanol)
  Compuestos apolares (aceites, resinas, ceras) → disolventes apolares (hexano, aceite vegetal)

DISOLVENTES COMUNES (de menos a más peligroso):
  Agua           → polar, segura, disuelve sales, azúcares, compuestos iónicos
  Etanol 96%     → polar-apolar, seguro para alimentos, extrae AE + compuestos polares
  Isopropanol    → similar al etanol, no para uso alimentario
  Aceite vegetal → apolar, seguro, extrae resinas liposolubles (cannabis lipid extraction)
  Acetona        → apolar, evapora rápido, no para alimentario, buena para lacas/resinas
  Hexano         → muy apolar, extractos más puros que acetona, inflamable y neurotóxico
```

### Tintura alcohólica (extracción con etanol)

```
MÉTODO:
  1. Material seco (hierba, corteza, raíz) → triturar → frasco de cristal
  2. Cubrir con etanol 60-80% (para tinturas medicinales) o vodka 40% (plantas aromáticas)
  3. Proporción: 1 parte de planta seca : 5 partes de etanol (p/v)
  4. Maceración: 4-6 semanas en oscuridad, agitar cada 2 días
  5. Filtrar con tela → exprimir → filtrar con papel de café → frasco oscuro
  6. Conservación: 3-5 años

TINTURAS ÚTILES:
  Tintura de propóleo (resina de abeja): propóleo + etanol 70%, 4 semanas → antibacteriana
  Tintura de cúrcuma: cúrcuma + etanol 60% → curcumina (en agua se disuelve mal)
  Tintura de lavanda: lavanda + etanol → base para fragancias caseras
```

### Extracción en frío — macerado en aceite

```
ENFLEURAGE (método tradicional de perfumería):
  Grasa neutra (manteca de cacao, aceite de oliva refinado) en bandeja
  Pétalos de flores encima → cubrir → 24h → retirar flores mustias → flores frescas
  Repetir 20-30 veces → el aceite se satura de compuestos aromáticos
  Resultado: "pomada" aromática o tintura en alcohol de la pomada

MACERADO SOLAR EN ACEITE:
  Hierbas secas + aceite de oliva en frasco → sol de verano, 3-4 semanas → filtrar
  Aceite infusionado de árnica, hipérico (St. John's Wort), caléndula → base de cremas
  El calor del sol extrae los compuestos liposolubles sin desnaturalizar
```

## Destilación de alcohol — el umbral legal

```
⚠ ADVERTENCIA LEGAL (España):
  La Ley 38/1992 (Impuestos Especiales) prohíbe la destilación privada de alcohol
  sin autorización del Departamento de Aduanas. El aguardiente casero puede implicar
  sanciones de 1000-3000€ y decomiso del equipo.

  Lo que SÍ es legal:
  ✓ Destilación de agua (alambique para agua purificada)
  ✓ Hidrodestilación de plantas (aceites esenciales e hidrolatos)
  ✓ Fermentación para consumo propio (vino, sidra, cerveza — sin destilar)

QUÍMICA DE LA FERMENTACIÓN (sin destilar):
  C₆H₁₂O₆ (glucosa) → 2C₂H₅OH + 2CO₂  (ΔG = −218 kJ/mol)
  Levadura Saccharomyces cerevisiae: máximo ≈ 15-18% etanol (inhibición por el propio alcohol)
  Sidra: manzana + levadura cider → 5-7% ABV
  Hidromiel: miel + agua + levadura champagne → 10-14% ABV
```

## Destilación fraccionada — separar mezclas

```
COLUMNA DE VIGREUX:
  Tubo de vidrio con indentaciones internas → aumenta la superficie de contacto
  Cada indentación = un plato teórico de destilación
  Cuantos más platos → mejor separación (mezclas más similares en T_eb)

EXPERIMENTO: separar acetona del agua
  Mezcla 50:50 acetona:agua → T_eb acetona 56°C, agua 100°C
  Sin columna: destilado inicial ≈ 80% acetona (no puro)
  Con columna Vigreux 30cm: destilado inicial ≈ 95% acetona

PRÁCTICA CASERA:
  Sin columna de Vigreux se puede usar un tubo largo de cobre enrollado como precolumna
  O la destilación se puede repetir ("redistilar") para purificar más
```

## CO₂ supercrítico — la frontera del estado del arte

```
Por encima de 31.1°C y 73.8 atm, el CO₂ está en estado supercrítico:
  → densidad de líquido pero viscosidad de gas → penetra como gas, disuelve como líquido
  → extrae AE sin dejar residuo de disolvente (el CO₂ se evapora al reducir la presión)
  → no destruye compuestos térmolábiles (vitaminas, terpenos delicados)

EQUIPOS: a partir de 3000€ (laboratorio) → no DIY, pero entender el principio aclara
  por qué los AE "CO₂ extract" son diferentes a los destilados:
  Más completos (incluyen ceras, resinas, componentes de alto PM que no destilan)
  Más similares al olor de la planta fresca
```

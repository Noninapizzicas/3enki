# Carpintería DIY

> Trabajar la madera con las manos y herramientas portátiles. El placer de construir algo que dura. Sin CNC, sin ordenadores — la relación directa con el material.

## La escalera del carpintero DIY

```
NIVEL 0 — BRICOLAJE BÁSICO:
  Taladro, sierra manual, tornillos y madera de bricolaje
  → Estanterías, cajas, soportes simples · materiales: tablero de melamina, DM, pino de bricolaje

NIVEL 1 — CARPINTERÍA PORTÁTIL:
  Sierra circular + guía, sierra de calar, lijadora orbital, fresadora manual
  → Muebles sencillos, estanterías flotantes, banco de trabajo
  → Materiales: pino macizo, pino laminado, tablero de pino/abeto

NIVEL 2 — TALLER FIJO:
  Sierra de mesa, sierra de inglete, cepilladora, grueso
  → Muebles de calidad, uniones sin metal, trabajo de precisión
  → Maderas: roble, haya, nogal, castaño

NIVEL 3 — EBANISTERÍA:
  Gubias, formones, torno de madera, marquetería
  → Piezas únicas, restauración, arte en madera
  → Maderas nobles: nogal americano, cerezo, wengué, ébano
```

## Primeros proyectos recomendados (por orden de complejidad)

```
NIVEL 0 (sin taller):
  Caja simple con tapa · estantería de pared · perchero de pared · banco para jardín (palets)

NIVEL 1 (sierra circular + taladro):
  Estantería flotante · mesa de centro · banco con cajón · cajas con juntas a inglete

NIVEL 2 (taller básico):
  Banco de carpintero · mesa de comedor maciza · silla de madera · estantería empotrada

NIVEL 3 (taller completo):
  Armario con cajones de cola de milano · silla Windsor · mesa con mortajas y espigas

EL PRIMER PROYECTO ACONSEJADO:
  → Una caja simple (200×100×80mm) · con juntas a inglete · acabado con aceite
  → Aprende: medición, corte, cola de carpintero, lijado, acabado
  → Si queda bien: repite con cola de milano → mismo proyecto, mucho más valioso
```

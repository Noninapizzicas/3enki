# Awesome Maker — Referencia curada del movimiento maker

Lista curada de recursos maker: fabricación digital, herramientas, comunidades y proyectos. Cubre el ecosistema completo del hacedor.

## Fabricación digital

### Impresión 3D

| Nombre | Descripción |
|---|---|
| **PrusaSlicer** | Slicer open-source estándar |
| **Cura** | Slicer de Ultimaker, muy extendido |
| **OctoPrint** | Control web de impresoras 3D (8.8k stars) |
| **Klipper** | Firmware de alto rendimiento (11.8k stars) |
| **Marlin** | Firmware estándar RepRap (17.5k stars) |

### CNC y fresado

| Nombre | Descripción |
|---|---|
| **Grbl** | Controlador CNC open-source para Arduino (5k+ stars) |
| **LinuxCNC** | Controlador CNC completo: fresadora, torno, plasma, láser (2.4k stars) |
| **FluidNC** | CNC firmware para ESP32 con web UI WiFi |
| **Maslow CNC** | Router CNC gran formato (4×8 ft), ~$500 |
| **MPCNC (V1 Engineering)** | CNC mayormente impresa en 3D, multi-herramienta |

### Corte láser

| Nombre | Descripción |
|---|---|
| **LightBurn** | Software de control láser (comercial, referencia) |
| **LaserWeb** | Control láser open-source en navegador |
| **SVGnest** | Nesting vectorial con algoritmo genético (2.4k stars) |
| **Deepnest** | Nesting de escritorio con fusión de líneas comunes (1.1k stars) |

# FASE 2 — Pasada 1 (Esquematizar Negocio)

> Skill: `esquematizar-negocio`
> Evento de entrada: `negocio.identificado`
> Evento de cierre: no cierra — la pasada 1 abre el ciclo

## Qué hace

Primera ronda del prisma de 5 huecos sobre el negocio ya identificado:
IDENTIDAD · RESTRICCIONES · CONTRATO · NO-OBJETIVOS · PREGUNTAS_ABIERTAS.

Busca el FOCO por sí mismo: identifica el eslabón limitante del flujo
(cuello de botella) y lo expande al máximo.

## Qué lee

```
state/project_profile.json   ← identidad declarada en F0 (que_es, que_vende, como_lo_elabora, propósito)
```

## Qué crea

```
<proyecto>/esquemas/pasada-1-esquema.md    ← primera ronda del prisma
<proyecto>/esquemas/esquema.md             ← árbol maestro (se va construyendo)
```

## Ley de cero supuestos

Todo valor no declarado por el dueño se marca como PREGUNTA ABIERTA.
Nunca se estima, nunca se inventa. Un "no se puede" nunca se afirma: se pregunta.

## Siguiente

Las preguntas abiertas se hacen al dueño una a una. Se investiga lo investigable
(web). Con las respuestas → pasada 2.

## Q24 · En una disputa, ¿cómo se prueba y quién decide?

**La prueba es el acta. No hay testigos ni «me parece».**

```
ACTA DE UN REPARTO
  hora de aceptación · hora de llegada al local · hora de salida del local
  hora de llegada al portal · hora de entrega
  foto de entrega · posición del rider · posición del cliente declarada
  acuse de la propuesta (Q42) y desenlace
```

**Quien disputa no discute el hecho: discute la regla.**

```
discute el HECHO   → el acta zanja. No hay nada que hablar.
discute la REGLA   → no es una disputa, es una propuesta de cambio (Q26).
```

```
PLAZO      48 h para reclamar. Después, el acta es firme.
QUIÉN       nadie decide a mano. Decide el acta + la regla escrita.
            La revisión humana solo entra si el acta está incompleta.
```

## Q25 · ¿La revisión humana se construye desde el día uno?

**Sí.** No es una elección: la Directiva (UE) 2024/2831 la exige incluso para
repartidores no asalariados. Montarla después cuesta más — y el régimen
sancionador puede ser el doble.

```
QUIÉN      el dueño, en las primeras 48 h
QUÉ VE     el acta completa + la regla que se aplicó + el resultado
QUÉ DECIDE una de tres:
             1 · el acta es correcta y la regla está bien aplicada → se mantiene
             2 · el acta está incompleta                            → se anula el cargo
             3 · la regla es injusta                                → NO cambia el caso,
                                                                       cambia la regla (Q26)
```

**El volumen esperado es bajo.** Y esa es la señal: **si la revisión humana se
llena de casos, el problema no es la revisión — es la regla.** Una regla buena
genera pocas disputas.

## Q26 · ¿Quién firma el dictamen y qué efecto tiene?

```
FIRMA      el dueño (rol jefe)
EFECTO     cambia LA REGLA, no el caso
```

Y con dos límites que la hacen creíble:

```
1 · la regla nueva rige desde su fecha de publicación
2 · los casos anteriores NO se reabren
```

**El segundo límite es el que sostiene el mercado.** Si cada cambio de regla
reabriera el pasado, nadie podría fiarse de nada: ni el rider de lo que cobró,
ni la tienda de lo que pagó. Un marco que cambia hacia atrás no es un marco.

Y queda registrado: **quién, cuándo y por qué.** Si dentro de un mes alguien
pregunta por qué se cambió el umbral de espera, la respuesta está escrita y
fechada.

## Q34 · ¿Qué acredita el rider al darse de alta y quién lo verifica?

```
IDENTIDAD      nombre, documento, cuenta bancaria     → Stripe (KYC)
AUTÓNOMO       alta de actividad (036/037)             → documento
SEGURO         póliza de responsabilidad civil         → documento
VEHÍCULO       moto · coche · bici · patinete          → declarado
               define el volumen de carga y el €/km
REGLAS         se le informan POR ESCRITO y las acepta  → aceptación firmada
ANTIGÜEDAD     0. Empieza igual que todos.
```

**Y ese último punto es una decisión, no un descuido.** Ningún rider nuevo
entra con prioridad, ni con ventaja por antigüedad, ni con un trato especial.
Entra con las mismas reglas que el que lleva un año — porque el marco no
premia la fidelidad, premia que el trabajo se haga bien.

**Lo que se verifica y lo que no:**

```
Stripe verifica       identidad y cuenta (es su obligación legal)
Bocaos verifica       que los documentos estén y no estén caducados
Bocaos NO verifica    que el seguro cubra reparto (eso es del rider)
                      ni que el alta esté al día (eso es de Hacienda)
```

Bocaos guarda el documento y avisa cuando caduca. **No certifica**: no es una
autoridad, es un marco.

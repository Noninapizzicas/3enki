# Recetas mexicanas fundamentales — de casa a fiesta

Las recetas que toda cocina mexicana domina: desde el arroz rojo diario hasta el pozole de fiesta.

## Arroz rojo (arroz a la mexicana)

```
El acompañamiento universal — en todo plato corrido, en toda casa.

1. Remojar arroz 15min en agua caliente → enjuagar hasta agua clara
2. Secar bien (toalla o escurrir 15min)
3. Freír en aceite caliente hasta dorado (5-7min, revolviendo)
4. Licuar: tomate (2) + cebolla (1/4) + ajo (1 diente) + caldo
5. Añadir al arroz dorado → hervir → tapar → fuego mínimo 15min
6. Reposar 5min tapado → esponjar con tenedor

Secreto: el arroz se FRÍE primero (textura firme, no pegajoso)
```

## Frijoles (3 preparaciones base)

| Tipo | Método | Uso |
|---|---|---|
| **De la olla** | Frijol + agua + cebolla + epazote + sal → olla lenta 3-4h (o presión 40min) | Con todo — caldosos |
| **Refritos** | Frijoles de la olla → sartén con manteca + cebolla → machacar | Acompañamiento, tacos, tostadas |
| **Charros/borrachos** | Frijoles de la olla + tocino + chorizo + chile + cerveza | Carne asada, fiestas |

## Pozole

```
Plato ceremonial prehispánico (hoy = fiesta, cumpleaños, fines de semana)

Pozole rojo (Jalisco):
  1. Maíz cacahuazintle precocido → hervir hasta que reviente ("florece")
  2. Carne de cerdo (cabeza, espinazo, maciza) + sal
  3. Salsa: chile guajillo + ancho + ajo → licuar → colar → añadir al pozole
  4. Cocción larga hasta que todo se integre (2-3h)

  Servicio (cada comensal se sirve):
    - Lechuga picada
    - Rábano en rodajas
    - Cebolla picada
    - Orégano seco
    - Chile piquín
    - Tostadas
    - Limón
```

| Variante | Color | Región |
|---|---|---|
| **Rojo** | Chile guajillo + ancho | Jalisco, Nayarit |
| **Verde** | Pepita + tomate verde + chile poblano | Guerrero, Morelos |
| **Blanco** | Sin chile (caldoso) | Guerrero |

## Enchiladas

| Tipo | Salsa | Relleno | Región |
|---|---|---|---|
| **Rojas** | Chile guajillo + ancho | Pollo, queso | Nacional |
| **Verdes** | Tomatillo + serrano | Pollo | Nacional |
| **Suizas** | Verde + crema gratinada | Pollo | CDMX |
| **De mole** | Mole poblano | Pollo | Puebla |
| **Potosinas** | Chile ancho en la masa | Queso | San Luis Potosí |
| **Mineras** | Guajillo, fritas + rellenas | Queso, zanahoria | Guanajuato |

```
Técnica universal:
  1. Tortilla pasada por aceite caliente (3 seg por lado — flexible, no crujiente)
  2. Pasar por salsa (cubrir completamente)
  3. Rellenar y enrollar
  4. Bañar con más salsa + crema + queso + cebolla
```

## Chilaquiles

```
El desayuno de resaca:

  1. Tortillas cortadas en triángulos → freír hasta crujientes (totopos)
  2. Salsa verde o roja caliente
  3. Bañar los totopos con la salsa → mezclar (sin que pierdan todo el crujiente)
  4. Servir con: crema, queso fresco, cebolla, huevo frito o pollo encima

  Verdes = salsa verde (tomatillo + serrano)
  Rojos = salsa roja (guajillo + tomate)
  Divorciados = mitad verdes, mitad rojos en el mismo plato
```

## Mole poblano (simplificado para casa)

```
No son 30 ingredientes — esta versión es alcanzable:

Chiles: 4 ancho + 3 mulato + 2 pasilla (hidratados)
Tostar: almendras + ajonjolí + cacahuetes + pasas
Freír: cebolla + ajo + tomate
Especias: canela, clavo, pimienta, comino
Chocolate: 1 tablilla de chocolate mexicano
Tortilla: 1 tortilla tostada (espesante)

Todo → licuar con caldo → colar → freír en manteca 30min → caldo hasta consistencia.
Servir sobre pollo con ajonjolí y arroz rojo.
```

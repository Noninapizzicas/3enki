# Cocina japonesa — precisión y umami

Japón trata la comida como arte: máximo respeto al ingrediente, mínima transformación, presentación impecable. El umami nació aquí.

## Los 5 principios

| Principio | Japonés | Significado |
|---|---|---|
| **Estacionalidad** | 旬 (shun) | Solo ingredientes en su momento óptimo |
| **Equilibrio 5** | 五味五色五法 | 5 sabores, 5 colores, 5 métodos en cada comida |
| **Respeto** | いただきます | "Recibo humildemente" — gratitud al ingrediente |
| **Simplicidad** | 素 (so) | Menos es más — no tapar el sabor natural |
| **Presentación** | 盛り付け | El plato se come con los ojos primero |

## Dashi — el alma de la cocina japonesa

El caldo dashi (kombu + katsuobushi) contiene glutamato (kombu) + inosinato (katsuobushi) = sinergia umami × 8. Es la base invisible de casi todo plato japonés.

## Sushi — tipos y protocolo

| Tipo | Forma | Descripción |
|---|---|---|
| **Nigiri** | Óvalo de arroz + lámina encima | El clásico — se come invertido (pescado en lengua) |
| **Maki** | Rollo en nori | Hosomaki (fino), futomaki (grueso) |
| **Temaki** | Cono de nori | Informal, se come con la mano |
| **Sashimi** | Solo pescado, sin arroz | Purea del producto — el corte es todo |
| **Chirashi** | Bol de arroz + sashimi variado | Casual, generoso |

### Arroz de sushi

```
Arroz japonés de grano corto (Koshihikari)
  + vinagre de arroz (40ml/300g arroz)
  + azúcar (20g)
  + sal (8g)

Mezclar con movimiento de corte (no revolver), abaniquear para enfriar.
Temperatura ideal de servicio: temperatura corporal (36-38°C).
```

## Ramen — las 4 bases

| Base | Caldo | Perfil | Región |
|---|---|---|---|
| **Shoyu** | Pollo/cerdo + soja | Salado, clásico | Tokio |
| **Shio** | Pollo/pescado + sal | Limpio, delicado | Hakodate |
| **Miso** | Cerdo + miso | Robusto, invernal | Sapporo |
| **Tonkotsu** | Huesos de cerdo 12-18h | Cremoso, blanco, potente | Fukuoka |

### Toppings de ramen

| Topping | Preparación |
|---|---|
| **Chashu** | Panceta de cerdo enrollada, braseada en soja+mirin |
| **Ajitama** | Huevo marinado (6min cocción → soja+mirin 12-24h) |
| **Nori** | Alga tostada |
| **Menma** | Brote de bambú fermentado |
| **Negi** | Cebolleta picada fina |
| **Mayu** | Aceite de ajo negro |

## Kaiseki — alta cocina japonesa

```
Menú de 7-14 tiempos que sigue las estaciones:

1. Sakizuke — aperitivo (amuse-bouche)
2. Hassun — plato estacional (mar + montaña)
3. Mukōzuke — sashimi
4. Takiawase — verduras cocidas
5. Futamono — sopa con tapa
6. Yakimono — pieza a la brasa
7. Su-zakana — palate cleanser (vinagre)
8. Gohan — arroz, miso, tsukemono (pickles)
9. Mizumono — postre (fruta estacional)
```

| Plato | Descripción |
|---|---|

| **Karaage** | Pollo frito marinado en soja+jengibre |

| **Yakitori** | Brochetas de pollo a la brasa |
| **Takoyaki** | Bolitas de pulpo (Osaka) |
| **Okonomiyaki** | "Pizza" japonesa de col (Osaka/Hiroshima) |

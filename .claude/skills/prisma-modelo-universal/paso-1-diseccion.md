# Paso 1 — Diseccionador sobre prisma-modelo-universal

## Tarea

Modelar un producto de comercio con el molde universal de 5 huecos.

---

## PARTIR (verbos atómicos)

```
RECIBIR → DESCOMPONER → CLASIFICAR → VALIDAR → GUARDAR → DERIVAR
```

---

## CLASIFICAR (¿JUICIO o MECÁNICA?)

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | MECÁNICA_DURA |
| ¿Quién lo hace? | Cualquier ejecutor |

| ¿Qué falta? | Input ilegible → error |

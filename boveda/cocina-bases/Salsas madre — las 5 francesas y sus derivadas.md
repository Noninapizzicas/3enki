# Salsas madre — las 5 francesas y sus derivadas

Auguste Escoffier codificó 5 salsas madre de las que derivan cientos de salsas. Dominar estas cinco es dominar la salsa francesa.

## Las 5 salsas madre

| Salsa madre | Base | Espesante | Líquido | Temp. servicio |
|---|---|---|---|---|
| **Béchamel** | Mantequilla | Roux blanco | Leche | Caliente |
| **Velouté** | Mantequilla | Roux rubio | Fondo blanco (pollo/pescado/ternera) | Caliente |
| **Española** | Grasa | Roux oscuro | Fondo oscuro | Caliente |
| **Tomate** | Aceite/mantequilla | Tomate (pectina natural) | Fondo o agua | Caliente |
| **Holandesa** | Mantequilla clarificada | Yemas (emulsión) | — | Tibia (60-65°C) |

## Roux — la base del espesante

```
Roux = grasa + harina a partes iguales (peso)

Blanco:  1-2 min (no toma color) → béchamel
Rubio:   3-5 min (dorado pálido) → velouté
Oscuro:  8-15 min (marrón avellana) → española

Regla: cuanto más oscuro, menos espesa (el almidón se degrada)
Proporción: 60g roux por litro de líquido = salsa napante (cubre cuchara)
```

## Derivadas principales

### De Béchamel

| Derivada | Adición | Uso |
|---|---|---|
| **Mornay** | Gruyère + parmesano + yema | Gratinados, croquetas |
| **Soubise** | Cebolla confitada | Carnes blancas |
| **Nantua** | Mantequilla de cangrejo | Pescados, quenelles |
| **Crème** | Nata + reducción | Todo propósito |
| **Mustard** | Mostaza de Dijon | Cerdo, pollo |

### De Velouté

| Derivada | Adición | Uso |
|---|---|---|
| **Suprême** | Nata + champiñón + limón | Pollo |
| **Allemande** | Yema + limón + nuez moscada | Ternera |
| **Vin blanc** | Vino blanco + reducción de fumet | Pescado |
| **Bercy** | Chalota + vino + perejil | Pescado |
| **Poulette** | Champiñón + limón + perejil | Aves |

### De Española → Demi-Glace

| Derivada | Adición | Uso |
|---|---|---|
| **Demi-Glace** | Española + fondo oscuro reducido 1:1 | La reina — carnes |
| **Bordelaise** | Demi-glace + chalota + vino tinto + tuétano | Entrecot |
| **Chasseur** | Demi-glace + champiñón + tomate + estragón | Pollo, conejo |
| **Robert** | Demi-glace + cebolla + mostaza + vino blanco | Cerdo |
| **Madeira** | Demi-glace + vino de Madeira | Ternera, solomillo |
| **Périgueux** | Demi-glace + trufa | Lujo |

### De Holandesa

| Derivada | Adición | Uso |
|---|---|---|
| **Béarnaise** | Estragón + chalota + vinagre | Carnes a la brasa |
| **Choron** | Béarnaise + tomate concentrado | Pescado, huevos |
| **Maltaise** | Zumo de naranja sanguina | Espárragos |
| **Mousseline** | Nata montada | Pescado, verduras |

### De Tomate

| Derivada | Adición | Uso |
|---|---|---|
| **Provençale** | Ajo + aceite de oliva + hierbas | Pasta, verduras |
| **Portugaise** | Cebolla + ajo + perejil | Pescado |
| **Créole** | Pimiento + apio + cebolla | Arroz, gambas |
| **Napolitana** | Ajo + orégano + albahaca | Pasta |

## Proporciones maestras

| Componente | Por litro de salsa |
|---|---|
| **Roux** | 60g mantequilla + 60g harina |
| **Líquido** | 1 litro (leche, fondo, según madre) |
| **Sal** | 8-10g |
| **Nuez moscada** | 1 pizca (béchamel) |
| **Pimienta** | blanca (salsas claras), negra (oscuras) |

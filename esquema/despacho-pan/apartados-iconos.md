# Apartados · Iconos — set de iconografía de la web de consumo

> Refuerza la marca y guía el recorrido. Coherencia: un icono por acción, siempre el mismo.

## Set mínimo
- **Pan/repostería**: icono de producto (🍞 para pan, 🥐 bollería, 🍰 dulce, 🥨 salado).
- **Carrito**: 🛒 para "ver pedido".
- **Pago**: 💳 para "pagar".
- **Confirmación**: ✅ para "pedido confirmado".
- **Recogida**: 📦 para "listo para recoger".
- **Repetir**: 🔁 para "repetir mi pedido semanal".
- **Aviso**: 🔔 para recordatorios.

## Reglas
- **Un icono por acción**, siempre el mismo (coherencia).
- **Icono + texto**: nunca icono solo (diseño para mayores).
- **Los iconos refuerzan la marca**: tono cálido, no genérico.

## Guía del recorrido
- Descubrir → icono de producto.
- Elegir → selector (cantidad, franja).
- Convertir → carrito + pago.
- Confirmar → ✅.
- Recoger → 📦.
- Repetir → 🔁.

# Awesome Open Hardware — Referencia curada de hardware abierto

Lista curada de recursos para hacer proyectos de hardware open-source. 550+ estrellas en GitHub. Mantenida por el grupo de Open Hardware de TU Delft.

## Proyectos destacados por categoría

### Instrumentación científica

| Nombre | Descripción |
|---|---|
| **OpenFlexure** | Microscopio motorizado imprimible en 3D |
| **Open Gamma Detector** | Espectrómetro de rayos gamma de bajo coste |
| **OpenPCR** | Termociclador PCR open-source |
| **Pocket Science Lab** | Laboratorio de ciencias portátil (osciloscopio, generador, etc.) |

### Robótica

| Nombre | Descripción |
|---|---|
| **OpenDog** | Robot cuadrúpedo open-source de James Bruton |
| **MakersPet/oomwoo** | Robot aspirador open-source. 6.9k stars |
| **Stanford Pupper** | Cuadrúpedo ágil de bajo coste |
| **OpenBot** | Robot educativo que usa smartphone como cerebro |

### Fabricación digital

| Nombre | Descripción |
|---|---|
| **Precious Plastic** | Máquinas open-source para reciclar plástico (trituradora, extrusora, inyectora) |
| **FarmBot** | CNC de cultivo automatizado open-source |
| **Maslow CNC** | Router CNC gran formato (4×8 ft), ~$500 |
| **LumenPnP** | Pick-and-place open-source para ensamblaje PCB |

### Audio / Synth

| Nombre | Descripción |
|---|---|
| **Winterbloom** | Módulos eurorack open-source con documentación ejemplar |
| **Mutable Instruments** | Módulos eurorack cuyo firmware fue liberado como open-source |

### IoT y embebidos

| Nombre | Descripción |
|---|---|
| **Tasmota** | Firmware alternativo para dispositivos ESP. 24.6k stars |
| **ESPHome** | Firmware YAML para ESP con Home Assistant. 9k+ stars |
| **WLED** | Control de tiras LED por WiFi. 15k+ stars |
| **Meshtastic** | Red mesh LoRa off-grid. 8k stars |

# Cocina del Magreb — especias y tajines

Marruecos, Túnez, Argelia: la cocina del norte de África donde la especia es reina, el tajín es altar y el cuscús es pan.

## Las especias del Magreb

| Especia | Perfil | Uso |
|---|---|---|
| **Comino** | Terroso, cálido | Omnipresente — carne, legumbres, salsas |
| **Cúrcuma** | Terroso, color dorado | Color y base en tajines |
| **Canela** | Dulce-cálida | Tajines dulce-salado (cordero + ciruelas) |
| **Jengibre** | Picante, fresco | Tajines, marinadas |
| **Azafrán** | Floral, complejo | Cuscús, tajines de lujo |
| **Pimentón** | Dulce-ahumado | Salsas, marinadas |

### Ras el Hanout — "lo mejor de la tienda"

```
Mezcla de 12-30+ especias, varía por especiero:

Base: comino, cilantro, canela, jengibre, cúrcuma, pimienta
Medio: cardamomo, nuez moscada, clavo, pimentón
Alto: pétalos de rosa, lavanda, granos del paraíso, cubeba
Premium: azafrán, mace, galangal

No hay receta fija — cada especiero tiene su mezcla secreta.
```

### Harissa — la pasta picante tunecina

```
Chile guindilla seco + ajo + comino + cilantro + alcaravea + aceite de oliva
→ mortero o molino → pasta roja intensa

Uso: condimento universal en Túnez, salsa de dip, marinada, en cuscús
Variantes: harissa con rosa (Túnez), harissa ahumada, harissa suave
```

## Tajín — olla y plato

| Tipo | Ingredientes | Perfil |
|---|---|---|
| **Cordero con ciruelas** | Cordero, ciruelas, almendras, canela, miel | Dulce-salado — el clásico |
| **Pollo con limón y aceitunas** | Pollo, limón en conserva, aceitunas verdes | Ácido-salado |
| **Kefta** | Albóndigas, huevos, tomate, comino | Rústico, rápido |
| **Verduras** | Calabaza, garbanzos, zanahoria, pasas | Vegetariano |
| **Pescado** | Pescado entero, chermoula, verduras | Costero — Essaouira |

### Chermoula — la marinada del Magreb

```
Cilantro + perejil + ajo + comino + pimentón + limón + aceite de oliva
→ licuar → marinada para pescado (1-2h), pollo, verduras
```

## Cuscús

```
Sémola de trigo duro + vapor (couscoussier) en 3 pasadas

1ª pasada: vapor 15min → deshacer grumos con aceite, salar
2ª pasada: vapor 15min → hidratar con agua/caldo
3ª pasada: vapor 15min → mantequilla final

Se sirve en montaña con estofado de verduras + carne + caldo aparte
Viernes = día del cuscús en Marruecos
```

| Variante | País | Diferencia |
|---|---|---|
| **Cuscús marroquí** | Marruecos | 7 verduras, cordero, garbanzos |
| **Cuscús tunecino** | Túnez | Más picante (harissa), pescado en la costa |
| **Cuscús argelino** | Argelia | Merguez, más carne |

## Pastela (Bastilla) — el tesoro de Fez

```
Capas de warqa (como phyllo pero más fino):
  - Pollo deshilachado con cebolla, azafrán, jengibre
  - Huevos cuajados con hierbas
  - Almendras tostadas + canela + azúcar
  → horno hasta dorar → espolvorear azúcar glass + canela

Dulce + salado + crujiente + especiado = la pieza más compleja del Magreb
```

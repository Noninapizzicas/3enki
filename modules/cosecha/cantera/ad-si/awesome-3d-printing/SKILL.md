# Awesome 3D Printing — Referencia curada de impresión 3D

Lista curada de recursos de impresión 3D: impresoras, software, materiales y comunidades. 1.6k estrellas en GitHub.

## Impresoras open-source

| Nombre | Tipo | Descripción |
|---|---|---|
| **Prusa i3 MK3S+** | FDM | La impresora open-source más popular. Diseño RepRap |
| **Voron** | FDM/CoreXY | Comunidad de impresoras de alto rendimiento, diseño CoreXY cerrado |
| **RatRig V-Core** | FDM/CoreXY | CoreXY con marco de aluminio, gran volumen |
| **Positron V3** | FDM | Diseño compacto vertical innovador |
| **BigFDM** | FDM | Impresora gran formato open-source (fab-machines) |

## Materiales FDM

| Material | Temp | Propiedades |
|---|---|---|
| **PLA** | 190-220°C | Fácil, biodegradable, rígido, frágil |
| **PETG** | 230-250°C | Resistente, flexible, buena adhesión entre capas |
| **ABS** | 230-260°C | Resistente al calor, requiere cámara cerrada |
| **ASA** | 240-260°C | Como ABS pero resistente a UV (exteriores) |
| **TPU** | 220-250°C | Flexible, elástico |
| **Nylon (PA)** | 250-270°C | Muy resistente, higroscópico |
| **PC** | 270-310°C | Alta resistencia térmica y mecánica |
| **CF/GF relleno** | Variable | Fibra de carbono/vidrio en PLA/PETG/Nylon, alta rigidez |

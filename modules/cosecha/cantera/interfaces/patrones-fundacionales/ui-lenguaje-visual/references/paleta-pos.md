# Paleta POS · Variables CSS

Variables CSS que definen el lenguaje visual del POS.

```css
:root {
  /* Estados cocina (semáforo) */
  --estado-pendiente:    #f59e0b;
  --estado-pendiente-bg: rgba(245, 158, 11, 0.12);
  --estado-preparando:   #3b82f6;
  --estado-preparando-bg: rgba(59, 130, 246, 0.12);
  --estado-listo:        #22c55e;
  --estado-listo-bg:     rgba(34, 197, 94, 0.12);
  --estado-alerta:       #ef4444;
  --estado-alerta-bg:    rgba(239, 68, 68, 0.12);

  /* Tipos de cuenta */
  --tipo-local:    #3b82f6;
  --tipo-delivery: #f59e0b;
  --tipo-llevar:   #22c55e;
  --tipo-glovo:    #FF6B00;

  /* Botones especiales */
  --especial-mitad:   #8b5cf6;
  --especial-algusto: #ec4899;
  --especial-porcion: #0ea5e9;
}
```

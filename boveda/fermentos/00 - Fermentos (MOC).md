# Fermentos (MOC)

Mapa del sector. La fermentación es la transformación controlada de alimentos por microorganismos (bacterias, levaduras, hongos) que producen ácidos, alcohol, CO₂ u otros metabolitos. El resultado: sabor, conservación, biodisponibilidad y probióticos.

## Tipos fundamentales

| Tipo | Agente | Metabolito clave | Ejemplos |
|---|---|---|---|
| Lactofermentación | Bacterias ácido-lácticas (BAL) | Ácido láctico | Chucrut, kimchi, encurtidos, kvass |
| Fermentación alcohólica | Levaduras (Saccharomyces) | Etanol + CO₂ | Vino, sidra, cerveza, rejuvelac |
| Fermentación acética | Acetobacter spp. | Ácido acético | Vinagres |
| Fermentación simbiótica | SCOBY (BAL + levaduras) | Ácido láctico + acético + CO₂ | Kombucha, kéfir de agua |
| Fermentación de lácteos | BAL termofílicas/mesofílicas | Ácido láctico | Kéfir de leche, yogur |
| Fermentación por hongos | Aspergillus, Rhizopus, Bacillus | Enzimas + metabolitos | Miso (koji), tempeh, natto |

## Variables universales de control

```
TEMPERATURA: la variable más crítica
  < 15°C → fermentación muy lenta (conservación) · buena para chucrut largo
  15-22°C → mesofílica (kéfir, kombucha, vinagre, chucrut activo)
  30-37°C → termofílica (yogur, tempeh activo, natto)
  > 42°C → muerte de la mayoría de cultivos · pasteurización no deseada

pH: indicador de avance y seguridad
  > 4.6 → zona de riesgo (Clostridium botulinum puede crecer si no hay sal suficiente)
  3.5-4.5 → zona segura lactofermentación · pH 4.0 = chucrut maduro típico
  3.0-3.5 → kombucha madura, vinagres en proceso
  < 3.0 → muy ácido, vinagres maduros

SAL (NaCl) en lactofermentación:
  1.5-2% → fermentación rápida · mayor riesgo kahm
  2-3% → el rango ideal (inhibe patógenos, permite BAL)
  > 5% → muy lento · inhibe también las BAL · conservación en salmuera estática
```

## Escalera de complejidad

```
★☆☆ MÁS FÁCIL:
  Encurtidos lactofermentados (pepinillo, zanahoria, col)
  Kéfir de leche (los gránulos hacen el trabajo)
  Kombucha primera fermentación

★★☆ INTERMEDIO:
  Chucrut y kimchi (control de tiempo y sal)
  Kéfir de agua (más sensible que el de leche)
  Kombucha segunda fermentación (carbonatación → presión)
  Vino de frutas (densímetro, higiene)
  Vinagre de vino

★★★ AVANZADO:
  Cerveza casera todo grano (maceración, mash, lúpulo)
  Miso (3-12 meses, koji)
  Tempeh (inoculante específico, temperatura controlada 28-32°C, 36-48h)
  Natto (Bacillus subtilis natto, 40-42°C, difícil fuera de Japón)
```

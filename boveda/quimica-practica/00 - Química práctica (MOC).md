# ⚗️ Química práctica — mapa

> La química no ocurre solo en laboratorios universitarios. Con reactivos de droguería,
> ferretería y tiendas de acuario se pueden hacer experimentos reales, entender fenómenos
> cotidianos y fabricar cosas útiles. Este sector es el **taller químico doméstico**.

## El arco de lo práctico

```
Electrones en movimiento  →  [[Electroquímica — electrólisis, galvanotecnia, pilas]]
Orden desde el caos       →  [[Cristales — crecimiento y síntesis]]
Limpieza y superficies    →  [[Saponificación y tensioactivos — jabones, champús, detergentes]]
Esencias y extractos      →  [[Destilación y extracción — aceites esenciales, hidrolatos]]
Ácido, base, equilibrio   →  [[pH, ácidos y bases — indicadores naturales y buffers]]
Color en la materia       →  [[Tintes y pigmentos — naturales, mordientes, ecoprint]]
Materia que se construye  →  [[Polímeros y bioplásticos — epoxi, almidón, biorresinas]]
Ver lo que hay dentro     →  [[Análisis en el laboratorio casero — cromatografía, TLC, titulación]]
```

## Conceptos transversales

- **Estequiometría** — moles, masa molar, rendimiento de reacción: la base de todo
- **Equilibrio químico** — Le Chatelier, Ksp, pH de tampón
- **Cinética** — temperatura, catalizadores, superficie de contacto
- **Termodinámica** — ΔG, entalpía de reacción, espontaneidad

## Reactivos de acceso fácil (droguería / ferretería / acuario)

| Reactivo | Nombre común | Uso |
|---|---|---|
| NaOH | Sosa cáustica, desatascador | Jabones, electrólisis |
| H₂SO₄ diluido | Ácido de batería (diluir) | Pilas, grabado |
| HCl | Ácido muriático (ferretería) | Limpieza, grabado cobre |
| CH₃COOH | Vinagre (5-8%) o ácido acético glacial | pH, tintes |
| KAl(SO₄)₂·12H₂O | Alumbre de potasio (farmacia) | Cristales, mordiente |
| CuSO₄·5H₂O | Sulfato de cobre (ferretería/acuario) | Cristales, galvanotecnia |
| Na₂S₂O₃ | Hiposulfito sódico (foto, acuario) | Fijador, neutralizador Cl |
| KMnO₄ | Permanganato de potasio (farmacia) | Oxidante, indicador |
| H₂O₂ al 30% | Agua oxigenada técnica (droguería) | Oxidante, blanqueo |
| CaCO₃ | Carbonato cálcico (piedra caliza, Kalkwasser) | Buffer, indicador |
| Na₂CO₃ | Carbonato sódico (soda washing) | Bases suaves, textil |
| FeCl₃ | Cloruro férrico (electrónica) | Grabado de PCBs |

# Cocina india — especias y regiones

India es un continente culinario: 28 estados, cada uno con cocina propia. El hilo común son las especias (masala), el dominio del vegetarianismo y el concepto de curry como técnica, no como especia.

## Norte vs Sur — las dos Indias

| Aspecto | Norte | Sur |
|---|---|---|
| **Carbohidrato** | Pan (naan, roti, paratha) | Arroz, dosa, idli |
| **Grasa** | Ghee (mantequilla clarificada) | Aceite de coco, aceite de mostaza |
| **Proteína** | Más carne (mughal influence) | Más vegetariana |
| **Picante** | Moderado, cremoso | Alto, más seco |
| **Lácteos** | Paneer, yogur, raita | Más coco, tamarindo |
| **Estilo** | Mughal: korma, biryani, tandoori | Masala dosa, sambar, rasam |

## Especias esenciales (masala box)

Toda cocina india tiene una caja de especias (masala dabba) con 7 compartimentos:

| Especia | Hindi | Función | Uso |
|---|---|---|---|
| **Cúrcuma** | हल्दी (haldi) | Color, antiinflamatorio | Base de todo curry |
| **Comino** | जीरा (jeera) | Terroso, cálido | Tadka, curries, arroz |
| **Cilantro** | धनिया (dhaniya) | Cítrico, suave | Curries, chutneys |
| **Chile rojo** | लाल मिर्च (lal mirch) | Picante | Graduable |
| **Mostaza** | राई (rai) | Picante, pop en aceite | Tadka (sur), pickles |
| **Garam masala** | गरम मसाला | Mezcla cálida | Final de cocción |
| **Fenogreco** | मेथी (methi) | Amargo-dulce, maple | Curries del norte |

### Garam masala — la mezcla

```
No hay UNA receta — cada familia tiene la suya:

Base: comino + cilantro + pimienta negra
Cálida: canela + cardamomo + clavo
Opcional: macis, nuez moscada, hojas de laurel indio

Se TUESTA en seco y se MUELE fresco.
Se añade al FINAL de la cocción (no al principio).
```

## Tadka/Tempering — la técnica india universal

```
Tadka (तड़का) = freír especias en aceite/ghee caliente

1. Calentar ghee o aceite
2. Añadir especias enteras: mostaza, comino, fenogreco, curry leaves
3. Esperan 10-30 segundos (chisporrotean, cambian color)
4. Verter sobre el plato terminado (dhal, raita, arroz)

El aceite infusionado explota el sabor de las especias al calentarlas
en grasa — libera compuestos liposolubles que el agua no puede.
```

## Platos fundamentales

| Plato | Región | Descripción |
|---|---|---|
| **Butter chicken** | Punjab | Pollo tandoori en salsa de tomate + mantequilla + nata |
| **Biryani** | Hyderabad | Arroz basmati + carne + especias en capas (dum) |
| **Dhal** | Nacional | Lentejas con tadka — 100+ variantes |
| **Tandoori** | Punjab | Carne marinada en yogur + especias, horno tandoor (400°C+) |
| **Rogan josh** | Kashmir | Cordero en salsa de chile de Kashmir + yogur |
| **Masala dosa** | Karnataka | Crepe de arroz+lenteja rellena de patata |
| **Sambar** | Tamil Nadu | Guiso de lentejas + verduras + tamarindo |
| **Chole bhature** | Punjab | Garbanzos + pan frito inflado |
| **Palak paneer** | Norte | Espinacas + queso fresco |
| **Vindaloo** | Goa | Cerdo + vinagre + chile (herencia portuguesa) |

## Pan indio

| Pan | Harina | Cocción | Región |
|---|---|---|---|
| **Naan** | Maida (refinada) | Tandoor (pegado a pared) | Norte |
| **Roti/chapati** | Atta (integral) | Tawa (plancha) | Nacional |
| **Paratha** | Atta, laminado con ghee | Tawa + ghee | Norte |
| **Puri** | Atta | Fritura (se infla) | Nacional |
| **Dosa** | Arroz + urad dal (fermentada) | Tawa (crepe fino) | Sur |
| **Appam** | Arroz (fermentada) | Wok especial (bordes finos, centro grueso) | Kerala |

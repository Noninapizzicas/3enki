# Mise en place y organización de cocina

"Todo en su lugar" — el principio que separa al cocinero amateur del profesional. La mise en place es preparar TODOS los ingredientes y herramientas ANTES de encender el fuego.

## Mise en place: qué incluye

| Fase | Acción | Ejemplo |
|---|---|---|
| **Leer** | Leer la receta completa antes de tocar nada | Identificar tiempos, técnicas, equipos |
| **Medir** | Pesar y medir todos los ingredientes | Bol para cada ingrediente |
| **Cortar** | Todos los cortes hechos | Cebolla en brunoise, ajo laminado |
| **Temperar** | Sacar del frío lo que necesita temperatura | Carne 30min antes, mantequilla |
| **Preparar** | Mezclas previas listas | Especias mezcladas, huevos batidos |
| **Equipo** | Sartenes, ollas, utensilios seleccionados | Sartén precalentando, horno encendido |
| **Espacio** | Superficie de trabajo limpia y organizada | Basura cerca, trapos, tablas |

## Organización de la estación de trabajo

```
┌─────────────────────────────────────────┐
│           ZONA DE SERVICIO              │
│          (platos, decoración)           │
├─────────────────────────────────────────┤
│     FUEGO          │     FUEGO          │
│   (sartén 1)       │   (sartén 2)       │
├─────────────────────────────────────────┤
│  TABLA DE CORTE    │  INGREDIENTES      │
│  (cuchillo, trapo) │  (boles mise)      │
├─────────────────────────────────────────┤
│           ZONA DE LAVADO                │
│        (fregadero, basura)              │
└─────────────────────────────────────────┘
```

## La brigada de cocina (Escoffier)

| Puesto | Función | Estación |
|---|---|---|
| **Chef ejecutivo** | Dirige, crea menú, gestiona | No cocina (en grandes brigadas) |
| **Sous chef** | Segundo al mando, supervisa | Donde haga falta |
| **Chef de partie** | Responsable de una estación | Su estación |
| **Saucier** | Salsas, sofritos, salteados | Caliente |
| **Poissonnier** | Pescados y mariscos | Caliente |
| **Rôtisseur** | Asados, parrilla | Caliente |
| **Pâtissier** | Postres, pan, masas | Pastelería |
| **Garde manger** | Fríos: ensaladas, embutidos, buffet | Frío |
| **Entremetier** | Sopas, verduras, huevos | Caliente |
| **Tournant** | Comodín — cubre cualquier estación | Rotativo |

## Flujo de trabajo eficiente

| Principio | Regla |
|---|---|
| **Limpia mientras cocinas** | Cada pausa = limpiar una superficie |
| **Primero lo lento** | Pon a hervir el agua / precalienta el horno PRIMERO |
| **Agrupa tareas** | Corta todo junto, luego cocina todo junto |
| **FIFO** | First In, First Out — lo viejo se usa primero |
| **Etiqueta todo** | Fecha + contenido en cada recipiente del frío |
| **Degusta siempre** | Prueba en cada paso — sal, ácido, equilibrio |

## Tiempos de servicio: la coordinación

```
El plato se sirve cuando TODOS sus componentes están listos A LA VEZ.

Estrategia:
  1. Identificar el componente más lento (asado, braseado)
  2. Calcular hacia atrás: "si el asado tarda 40min, empiezo a los -40min"
  3. Intercalar los rápidos: "la salsa tarda 8min, empiezo a los -10min"
  4. Lo fresco al final: "la ensalada a los -2min"
  5. Emplatar todo junto en el minuto 0
```

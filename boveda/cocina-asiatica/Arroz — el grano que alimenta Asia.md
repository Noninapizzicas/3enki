# Arroz — el grano que alimenta Asia

El arroz alimenta a 3.5 mil millones de personas. Es el carbohidrato base de toda cocina asiática y de buena parte de la mediterránea y latinoamericana.

## Variedades principales

| Variedad | Grano | Almidón | Textura cocido | Uso |
|---|---|---|---|---|
| **Japónica (Koshihikari)** | Corto, redondo | Alto amilopectina | Pegajoso, brillante | Sushi, onigiri, arroz japonés |
| **Índica (Basmati)** | Largo, fino | Alto amilosa | Suelto, esponjoso | Biryani, pilaf, arroz indio |
| **Jasmine (Thai)** | Largo, aromático | Medio | Ligeramente pegajoso, floral | Arroz tailandés, vietnamita |
| **Bomba (Valencia)** | Medio, redondo | Absorbe 3× volumen | Suelto, absorbe sabor | Paella |
| **Glutinoso (sticky)** | Corto, opaco | Casi todo amilopectina | Muy pegajoso | Mango sticky rice, mochi, lao |
| **Arborio/Carnaroli** | Medio | Alto amilopectina | Cremoso | Risotto |
| **Arroz roto (tấm)** | Fragmentos | Variable | Textura irregular | Cơm tấm vietnamita |

## Cocción por tipo

### Arroz japonés (absorción)

```
1. Lavar 3-4 veces hasta agua clara (eliminar almidón superficial)
2. Remojar 30min
3. Agua: ratio 1:1.1 (arroz:agua)
4. Hervir → bajar a mínimo → tapa cerrada 12min
5. Reposar 10min sin abrir
```

### Arroz basmati (indio)

```
1. Lavar hasta agua clara
2. Remojar 30min (los granos se hidratan y alargan)
3. Hervir en abundante agua (como pasta) 10-12min
4. Colar, volver a la olla, tapa con trapo 5min
O: método absorción 1:1.5, fuego bajo 15min
```

### Arroz para paella

```
NO lavar (queremos el almidón para que absorba sabor)
NO tapar (queremos que evapore)
NO remover (nunca, jamás)
Fuego fuerte → añadir arroz al caldo hirviendo → 18-20min
Socarrat: fuego alto los últimos 2min
```

## Arroz frito — principios universales

```
La regla #1: ARROZ FRÍO (del día anterior, refrigerado)
  - El almidón retrogradado es firme y no se pega
  - Arroz caliente = masa pegajosa en el wok

Técnica:
  1. Wok a fuego alto + aceite con alto punto de humo
  2. Huevo primero (revolver rápido, trozos grandes)
  3. Arroz frío → romper grumos → fuego alto 2min
  4. Proteína + verduras (precocinadas)
  5. Sazón al final: soja, fish sauce, sal
  6. Cebolleta y sésamo para terminar
```

| Arroz frito | País | Sazón particular |
|---|---|---|
| **Chǎofàn** | China | Soja + sésamo |
| **Khao pad** | Tailandia | Fish sauce + lima |
| **Nasi goreng** | Indonesia | Kecap manis + sambal |
| **Bokkeumbap** | Corea | Gochujang + sésamo |
| **Yakimeshi** | Japón | Soja + mirin |

## Arroz en el Mediterráneo

| Plato | País | Tipo arroz | Técnica |
|---|---|---|---|
| **Paella** | España | Bomba | Absorción sin tapa, socarrat |
| **Risotto** | Italia | Arborio/Carnaroli | Añadir caldo poco a poco, remover |
| **Pilaf** | Turquía/Persia | Basmati | Tostar en grasa → caldo → tapa |

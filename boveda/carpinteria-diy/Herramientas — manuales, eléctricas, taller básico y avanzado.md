# Herramientas — manuales, eléctricas, taller básico y avanzado

## La filosofía del taller

```
REGLA DE ORO: las herramientas de mano primero, las eléctricas después
  → Un carpintero que no sabe usar un formón no mejorará con una fresadora
  → Las herramientas de mano enseñan a leer la madera · las eléctricas aceleran el trabajo

NO COMPRES TODO A LA VEZ:
  La trampa del taller: acumular herramientas sin dominar ninguna
  → Compra la herramienta CUANDO la necesites para un proyecto concreto
  → Alquila antes de comprar para saber si la necesitas realmente
  
CALIDAD VS PRECIO:
  Herramientas de mano: compra calidad desde el principio (duran décadas · las baratas frustran)
  Herramientas eléctricas: las de gama media (Bosch Verde, Makita) son suficientes para DIY
  → Evitar la gama más baja (Powerfix, ciertas marcas de bazar) en herramientas de corte
  → Las herramientas de segunda mano de calidad (Makita, DeWalt) son una excelente opción
```

## Kit mínimo — nivel 0 (sin taller)

```
MEDICIÓN Y MARCADO (IMPRESCINDIBLE):
  Cinta métrica 5m: Stanley FatMax o similar · buen anclaje · lectura clara
  Escuadra de carpintero 90°: marca ángulos rectos en todas las piezas · precio: 8-15€
  Falsa escuadra (bisel): para ángulos distintos de 90° · 8-12€
  Gramil: marca líneas paralelas al canto · indispensable para las juntas · 15-30€
  Lápiz de carpintero plano: no rueda de la mesa
  Cuchillo de marcar (marking knife): más preciso que el lápiz para juntas · 15-25€

CORTE MANUAL:
  Serrucho de costilla (tenon saw, serrucho de espigas): el más importante
    → Corte controlado para juntas · hoja rígida · paso fino · 20-50€
    → Marcas: Irwin, Bahco, Veritas (premium)
  Serrucho japonés (pull saw): corta al tirar · kerf finísimo · muy recomendado
    → Sustituto moderno del serrucho de costilla · 20-40€

ENSAMBLE:
  Martillo de carpintero (16-20oz): cabeza de hierro · mango de madera o fibra
  Mazo de madera o nylon: para ensamblar sin marcar · 15-25€
  Cola de carpintero (PVA): Titebond II o III · el III es resistente al agua · 15-20€ 1L
  Sargentos / mordazas (mínimo 4): el "tercer par de manos" del carpintero
    → Empezar con 2-4 sargentos de barra de 30cm y 2-4 de 60cm · marca: Bessey, Irwin
  
ACABADO MANUAL:
  Lija en pliego: grano 80, 120, 180, 240 · comprar en pliegos, no en tiras individuales
  Taco de lijar: bloque de madera o caucho para envolver la lija · 3-8€

TOTAL NIVEL 0: 150-300€
```

## Kit nivel 1 — herramientas eléctricas portátiles

```
SIERRA CIRCULAR (la más versátil):
  Para qué: cortes rectos en tableros y tablas · con guía = precisión alta
  Recomendada: Bosch PKS 55 A (190mm, 1200W) · Makita HS7601 · 80-150€
  → Hoja: 40 dientes para madera fina · 24 dientes para cortes rápidos
  → ACCESORIO CLAVE: guía de paralelo o regleta de aluminio como guía lineal
  → Con guía y buen disco: cortes de la calidad de una sierra de mesa
  → Alternativa: sierra de mesa de banco (más precisa pero menos versátil y más cara)

SIERRA DE CALAR:
  Para qué: cortes curvos, orificios, cortes en zonas sin acceso para circular
  Recomendada: Bosch PST 900 PEL · Makita 4350FCT · 60-120€
  → Hoja T101B: para madera sin astillar (corte por abajo) · imprescindible con melamina

TALADRO / ATORNILLADOR:
  Para qué: taladrar y atornillar · sin él no se puede hacer nada
  Recomendado: Bosch GSB 18V (percutor inalámbrico) · Makita DHP482 · 80-180€ con batería
  → Kit 18V compatible (sierra + taladro + linterna con la misma batería): muy práctico

LIJADORA ORBITAL:
  Para qué: lijar superficies planas antes de acabar · imprescindible para superficie limpia
  Recomendada: Bosch PEX 220 A (125mm) · Makita BO5041 · 40-80€
  → Hojas: 80, 120, 180, 240 grit
  → También existe la lija de banda: más agresiva · para quitar mucho material rápido

FRESADORA MANUAL (router):
  Para qué: chaflanes, ranuras, perfiles, enrutado de juntas, guías para cajones
  Recomendada: Bosch POF 1200 AE · Makita RT0701C (la mejor gama media) · 80-180€
  → Fresas básicas: recta de 6mm, recta de 12mm, chaflán 45°, media caña, rodamiento de copia
  → Con guía paralela y plantilla: puede hacer ranuras perfectas para cajones y uniones

TOTAL NIVEL 1: 400-800€ (sin sierra de mesa)
```

## Kit nivel 2 — taller fijo

```
SIERRA DE MESA (la reina del taller):
  Para qué: cortes rectos de precisión · rip cuts (a lo largo de la veta) · con guía = exactitud milimétrica
  Opciones DIY:
  → Bosch GTS 10 XC (la más vendida en bricolaje avanzado): 500-700€
  → Dewalt DWE7485: 400-600€ · buena relación calidad/precio
  → Sierra de mesa DIY: una buena sierra circular + mesa casera (muy popular en YouTube)
  → Hoja: 40-60 dientes ATB para madera limpia
  Alternativa: Sierra de banco compacta (Bosch PTS 10): 150-250€ · menos potente pero ocupa menos
  
SIERRA DE INGLETE (ingleteadora, sierra de cortar ángulos):
  Para qué: cortes a ángulo precisos · marcos · zócalos · piezas repetidas a medida
  Recomendada: Bosch GCM 8 SJL · Makita LS0815FL · 300-600€
  → Con extensión deslizante: corta tablones anchos
  → Puede sustituirse parcialmente con sierra circular + guía de ángulos

CEPILLADORA DE CARA (jointer):
  Para qué: dejar una cara plana de referencia · el primer paso del escuadrado
  Recomendada: Scheppach HM100L (260mm) · 300-600€
  → Imprescindible si trabajas madera aserrada (no calibrada) · innecesaria con tablero

GRUESO (cepilladora de gruesos, thicknesser):
  Para qué: llevar la segunda cara paralela a la primera (escuadrar el grosor)
  Recomendada: Makita 2012NB · DeWalt DW733 · 400-800€
  → Cepilladora + grueso = el par indispensable del trabajo en madera maciza

ESPIGADORA DOMINO (Festool):
  Para qué: juntas de espiga redonda de alta precisión sin habilidades de mortajado
  → El Festool Domino DF 500 (~900€) hace juntas perfectas en minutos · muy popular en talleres de semiprofesionales
  → Alternativa económica: espigadora de espigas redondas estándar · 40-80€

TORNILLO DE BANCO (vise):
  Para qué: sujetar la pieza mientras se trabaja con las manos libres
  → El de cara (front vise): sujeción frontal · ideal para cepillar y dar forma
  → El de cola (leg vise): para piezas largas en vertical
  → Anclado al banco de trabajo · 60-250€ según tipo y tamaño

TOTAL NIVEL 2: 1.500-4.000€ (según marcas y equipamiento)
```

## Herramientas de mano — las que forman al carpintero

```
CEPILLOS DE MANO:
  Cepillo de alisar n°4 (smoother): el más versátil · quita poco material · deja la superficie lista para acabar
  Cepillo n°5 (jack plane): más largo · para aplanar superficies grandes · quita más material
  Cepillo de bloque (block plane): pequeño · para chaflanes, cantos, ajustes finos
  → Marcas: Veritas (Canadá, las mejores a precio razonable) · Lie-Nielsen (premium americano)
  → Marcas antiguas recuperadas: Stanley vintage (hay muchas en segunda mano · se restauran)
  → AFILA SIEMPRE antes de usar: un cepillo desafilado no sirve de nada

FORMONES Y ESCOPLOS:
  Formones de biselar (bench chisels): juego de 4-6 anchos (6, 12, 19, 25, 32mm)
    → Marcas: Narex (checos · excelente calidad-precio · 8-15€/ud) · Pfeil · Two Cherries
    → Afila antes de cada sesión de trabajo
  Escoplo de mortajar (mortise chisel): sección cuadrada · para extraer madera en mortajas
    → Más grueso y resistente que los formones de biselar
  Gubia (gouge): para trabajos curvos · tallado · canales cóncavas

SERRUCHOS JAPONESES (los más recomendados hoy):
  Gyokucho 770 (240mm): la referencia · 20-30€
  Suizan: calidad similar · similar precio
  → Los pull saws japoneses cortan al tirar (no al empujar) → más control · kerf finísimo (0.3-0.5mm)
  → Para principiantes: más fáciles de usar que los serruchos occidentales

MAZOS:
  Mazo de madera: para golpear formones sin dañarlos · 20-40€ · o fácilmente fabricado en el taller
  Mazo de nylon/caucho: para ensamblar sin marcar la madera · 10-20€

RASQUETAS:
  Rasqueta de gabinete (card scraper): una delgada chapa de acero con rebaba
  → La herramienta más infravalorada del taller · produce superficies mejores que la lija
  → Sirve después del cepillo · antes del acabado · ideal para maderas con veta rebelde
  → Precio: 5-15€ · se afila con una lima redonda o una herramienta de bruñir
```

## Marcas y dónde comprar

```

  Bosch Verde (bricolaje): fiables · buena red de servicio · precio razonable

  DeWalt: orientado al profesional · batería 18V FLEXVOLT interesante
```

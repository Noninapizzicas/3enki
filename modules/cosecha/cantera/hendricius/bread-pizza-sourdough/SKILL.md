# Hendricius — Trilogía del pan artesanal

Tres repos complementarios del mismo autor (11k+ estrellas combinadas) que cubren la panadería desde fundamentos hasta maestría en masa madre.

## Los tres repos

| Repo | Estrellas | Enfoque |
|---|---|---|
| **the-bread-code** | 4.1k | Aprender a hacer pan como programador |
| **pizza-dough** | 3.6k | Masa de pizza napolitana perfecta |
| **the-sourdough-framework** | 3.6k | Libro open-source de masa madre |

### Fórmulas clave documentadas

| Parámetro | Valor típico | Rango |
|---|---|---|
| **Hidratación** | 65-75% | 50-85% según tipo |
| **Sal** | 2% del peso de harina | 1.8-2.2% |
| **Levadura fresca** | 2-5% | ajustar por temperatura |
| **Temperatura masa** | 24-26°C | crítico para fermentación |
| **Fermentación bulk** | 4-12h | según temperatura y levadura |

## pizza-dough — Napolitana

Protocolo completo para pizza napolitana auténtica:

| Fase | Detalle |
|---|---|
| **Poolish** | Pre-fermento 12-24h (opcional pero recomendado) |
| **Hidratación** | 65-70% para horno casero, 55-60% para horno de leña |
| **Harina** | Tipo 00 (Caputo Pizzeria), W 260-280 |
| **Fermentación** | Bulk 6-24h → bolas → 4-24h frío |
| **Horneado** | 250°C+ horno casero / 450°C+ horno de leña |

## the-sourdough-framework — Masa madre

Libro completo open-source que cubre:

| Capítulo | Contenido |
|---|---|
| **Starter** | Crear y mantener madre, ratios de alimentación |
| **Ciencia** | Microbiología (lactobacillus + levaduras salvajes) |
| **Fórmulas** | Pan de campo, centeno, integral, multi-grano |
| **Troubleshooting** | Starter muerto, miga densa, corteza blanda |
| **Avanzado** | Cold retard, autolyse extendida, laminación |

## Valor para referencia

- Troubleshooting visual (fotos de migas buenas vs problemas)

# Bebidas mexicanas — de horchata a mezcal

México tiene una cultura de bebidas tan rica como su cocina. Desde las aguas frescas prehispánicas hasta los destilados de agave, cada bebida cuenta una historia.

## Aguas frescas

| Agua | Base | Preparación |
|---|---|---|
| **Horchata** | Arroz + canela + vainilla + azúcar | Remojar arroz, licuar, colar, enfriar |
| **Jamaica** | Flor de jamaica (hibiscus) | Hervir flores, azúcar, enfriar |
| **Tamarindo** | Pulpa de tamarindo + azúcar + chile | Hervir, colar, enfriar |
| **Limón** | Limón + azúcar | Exprimir, agua, hielo |
| **Guanábana** | Guanábana + leche o agua | Licuar |
| **Sandía** | Sandía + limón | Licuar |
| **Tepache** | Piña (cáscara + pulpa) + piloncillo | Fermentar 2-3 días |

## Bebidas calientes prehispánicas

| Bebida | Base | Nota |
|---|---|---|
| **Atole** | Masa de maíz + agua + piloncillo + canela | Espeso, reconfortante — desayuno con tamales |
| **Champurrado** | Atole + chocolate | La versión con cacao |
| **Chocolate** | Cacao + azúcar + canela + agua/leche | Batido con molinillo hasta espumar |
| **Pozol** | Masa de maíz fermentada + cacao | Chiapas, Tabasco — prehispánico |
| **Pinole** | Maíz tostado molido + canela + azúcar + agua | Energético — los tarahumaras lo usan para correr |

## El agave — destilados mexicanos

### Tequila

```
Agave azul (Agave tequilana Weber var. azul)
Solo de 5 estados (Jalisco + 4 estados parciales, DO)

Proceso:
  1. Jimador corta hojas con coa → piña (30-70 kg)
  2. Hornear piñas (horno de mampostería 48-72h o autoclave 8-12h)
  3. Moler → extraer jugos (mosto)
  4. Fermentar (levaduras, 3-7 días)
  5. Destilar (2 destilaciones en alambique de cobre)
  6. Reposar según categoría
```

| Categoría | Reposo | Perfil |
|---|---|---|
| **Blanco/plata** | 0-2 meses | Agave puro, fresco, vegetal |
| **Reposado** | 2-12 meses (barrica) | Suave, vainilla, caramelo |
| **Añejo** | 1-3 años (barrica) | Complejo, madera, especias |
| **Extra añejo** | 3+ años | Profundo, tipo cognac |

### Mezcal

```
Cualquier agave (30+ especies), cualquier estado con DO
El tequila es un TIPO de mezcal (solo de agave azul)

Diferencia clave: horno bajo tierra (humo → sabor ahumado)
  1. Piñas en horno de tierra (3-5 días, piedras + leña + tierra)
  2. Moler en tahona (piedra circular tirada por caballo)
  3. Fermentar en tina de madera (natural, sin levaduras añadidas)
  4. Destilar en alambique de cobre o barro

"Para todo mal, mezcal. Para todo bien, también."
```

| Tipo | Agave | Perfil |
|---|---|---|
| **Espadín** | A. angustifolia | 80% producción, equilibrado |
| **Tobalá** | A. potatorum | Silvestre, floral, raro |
| **Madrecuixe** | A. karwinskii | Herbal, mineral |
| **Tepeztate** | A. marmorata | 25+ años para madurar, complejo |

### Pulque

```
Aguamiel fermentada del agave (maguey pulquero)
NO destilado — cerveza de agave (4-7% alcohol)
Bebida prehispánica, sagrada para los aztecas

Se consume FRESCO (no se embotella bien, fermenta rápido)
Curados: pulque + fruta (guayaba, piñón, avena, nuez)
```

## Michelada — el cóctel de cerveza

```
Cerveza mexicana (clara o oscura)
  + limón
  + sal (escarchado)
  + salsa inglesa
  + salsa valentina o maggi
  + salsa picante
  + hielo

Variante "ojo rojo": + clamato (jugo de tomate con almejas)
```

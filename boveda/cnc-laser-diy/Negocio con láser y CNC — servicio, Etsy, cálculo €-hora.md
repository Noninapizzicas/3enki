# Negocio con láser y CNC — servicio, Etsy, cálculo €-hora

> La máquina que compraste como hobby se paga sola en pocos meses si sabes cobrar el tiempo de máquina, no solo el material — el error número uno de quien empieza a vender es calcular precio como si el láser fuera gratis.

---

## Modelos de negocio reales

```
CORTE PARA TERCEROS (servicio de fabricación bajo demanda)
  El cliente trae su propio archivo, tú cortas/grabas y cobras por tiempo de máquina +
  material. Bajo margen por pieza pero volumen predecible, poca inversión en diseño propio.

PERSONALIZACIÓN EN ETSY (venta directa de producto)
  Diseñas plantillas base (llaveros con nombre, tablas de cortar, letreros) y vendes el
  producto terminado personalizado. Mayor margen por pieza, requiere inversión en
  fotografía, listing, gestión de pedidos y atención al cliente.

FIESTAS Y EVENTOS
  Servicio in-situ (grabado de nombres en el momento, favores de boda personalizados) —
  tarifa por evento, normalmente la mejor relación €/hora del sector porque el cliente
  paga por experiencia además de por producto.

SEÑALÉTICA Y ROTULACIÓN PARA NEGOCIOS LOCALES
  Placas, letreros, menús de restaurante, cartelería de tienda — clientes B2B recurrentes,
  tickets más altos que particular, pero ciclo de venta más largo (presupuesto, revisión).
```

## Cálculo de tarifa por hora de máquina

```
FÓRMULA BASE
  Precio de venta = (Materiales + Mano de obra + Coste de máquina + Gastos generales)
                     ÷ (1 - margen deseado)

  Ejemplo con margen del 40%: dividir el coste total entre 0,6

DESGLOSE DE "COSTE DE MÁQUINA" (lo que la mayoría olvida incluir)
  → Amortización: precio de la máquina ÷ horas de vida útil estimadas
    Ejemplo: máquina de 1.000€, vida útil estimada 2.000h → 0,50€/h de amortización
  → Consumibles: lentes/espejos, filtros de carbón activo, tubo CO2 (si aplica)
  → Electricidad: potencia de la máquina + extracción + compresor de air assist en marcha
  → Mantenimiento: tiempo de limpieza de lente, calibración, sustitución de piezas

TARIFA OBJETIVO DE REFERENCIA (mercado anglosajón, orientativo)
  30-50$/hora de trabajo de grabado/corte como objetivo mínimo — por debajo de esa
  franja es difícil cubrir amortización + tiempo real invertido (diseño, preparación,
  post-procesado) de forma sostenible.
```

## Estructura de precio de un producto tipo

```
EJEMPLO: llavero personalizado en madera 3mm con nombre
  Material: 0,15-0,30€ (recorte de contrachapado)
  Tiempo de máquina: ~90 segundos de corte → coste de máquina + electricidad: ~0,10€
  Mano de obra (diseño de variable + preparación + empaquetado): 3-5 min → 1,50-2,50€
  Gastos generales (comisión Etsy ~6,5% + pago + envío si aplica): variable
  → Precio de venta razonable: 6-10€ por unidad, según mercado y diferenciación de diseño

EJEMPLO: letrero personalizado grande (30×40cm, MDF + backfill de pintura)
  Material: 3-5€ · Tiempo de máquina: 20-40 min · Post-procesado (pintura, lijado): 15-20 min
  → Precio de venta razonable: 25-45€ según complejidad de diseño y acabado
```

## Dónde vender y promocionar

```
ETSY
  El marketplace de referencia para personalización — SEO de producto (título, tags)
  determina gran parte del tráfico, la competencia en categorías genéricas (llaveros) es
  alta, mejor diferenciarse en nicho (regalos para una afición específica, idioma local)

TIENDA PROPIA + REDES LOCALES
  Instagram/Facebook con portfolio de trabajo, grupos locales de compraventa, mercadillos
  de artesanía — mejor margen (sin comisión de plataforma) pero requiere más esfuerzo de
  captación propia

FERIAS Y MERCADOS DE ARTESANÍA
  Venta directa con margen alto, además sirve de escaparate para pedidos personalizados
  posteriores — el coste de puesto/stand hay que incluirlo en el cálculo de rentabilidad
  del evento, no solo el material vendido
```

## Errores comunes al empezar el negocio

```
→ Cobrar solo el material, olvidando amortización de máquina y tiempo de diseño — el
  error más citado por quien deja el negocio tras unos meses "sin ganar nada".
→ No calcular el tiempo real de post-procesado (lijado, pintura, empaquetado, envío) —
  el tiempo de máquina es solo una parte del coste total de producir una pieza vendible.
→ Competir por precio en categorías saturadas de Etsy (llaveros genéricos) en vez de
  buscar nicho diferenciado con menos competencia directa.
→ No probar la resistencia del producto a uso real antes de vender en volumen — un
  llavero de madera fina se puede partir, una tabla de cortar sin sellar se puede agrietar.
→ Subestimar el tiempo de gestión de pedidos personalizados (revisar nombre, confirmar
  con cliente, corregir errores) al fijar plazos de entrega en la tienda online.
```

## Novedades 2025-2026

```
→ La demanda de personalización en Etsy sigue creciendo como categoría, con packs de
  diseño de temporada (Etsy sellers usando archivos de Creative Fabrica/Design Bundles)
  reduciendo el tiempo de diseño propio necesario para lanzar catálogo nuevo cada mes.
→ El coste de entrada a "negocio con máquina propia" sigue bajando conforme el diodo de
  20-40W se abarata (400-1.200€ frente a los 2.000€+ de hace unos años) — el punto de
  equilibrio para justificar la inversión con encargos reales es cada vez más accesible.
```

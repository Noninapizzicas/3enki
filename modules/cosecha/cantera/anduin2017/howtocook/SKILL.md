# HowToCook — Guía de cocina casera para programadores

El repo de cocina más popular de GitHub (101k+ estrellas). Recetas de cocina china casera escritas en Markdown con precisión de programador: cantidades exactas, tiempos, temperaturas.

## Estructura del repo

```
HowToCook/
├── dishes/
│   ├── home-cooking/     → recetas caseras diarias
│   ├── breakfast/        → desayunos
│   ├── soup/             → sopas y caldos
│   ├── staple/           → arroz, fideos, dumplings
│   ├── drink/            → bebidas
│   ├── condiment/        → condimentos y salsas
│   └── dessert/          → postres
├── tips/
│   ├── learn/            → fundamentos de cocina
│   ├── advanced/         → técnicas avanzadas
│   └── experience/       → experiencias y trucos
└── README.md             → índice completo
```

## Formato de receta

Cada receta sigue un template consistente:

| Sección | Contenido |
|---|---|
| **Materiales** | Ingredientes con cantidades exactas (gramos, ml) |
| **Pasos** | Instrucciones numeradas con tiempos y temperaturas |
| **Consejos** | Tips del autor, variaciones, errores comunes |

## Categorías principales

| Categoría | Ejemplos | Recetas |
|---|---|---|
| **Cocina casera** | Tomate con huevo, mapo tofu, kung pao chicken | 100+ |
| **Sopas** | Wonton, huevo con tomate, seaweed egg | 20+ |
| **Staples** | Arroz frito, dan dan noodles, jiaozi | 30+ |
| **Desayunos** | Congee, youtiao, huevos al vapor | 15+ |
| **Condimentos** | Chili oil, salsa de soja casera | 10+ |

## Filosofía

- Cantidades en gramos, no "al gusto" — reproducibilidad
- Fotos de cada paso
- Explicación del POR QUÉ de cada técnica
- Sin equipo especial — cocina doméstica normal
- Community-driven: PRs para nuevas recetas

## Valor para referencia

- Base de datos de técnicas de wok (fuego alto, aceite caliente, movimiento constante)
- Proporciones de salsas chinas fundamentales (soy sauce:vinegar:sugar ratios)
- Tiempos de cocción validados por la comunidad
- Técnicas de corte y preparación de ingredientes asiáticos

# Agricultura natural (MOC)

El suelo como **ecosistema vivo** — no un sustrato inerte que se llena de NPK sino una comunidad de hongos, bacterias, lombrices y raíces que, bien gestionada, alimenta la planta sin síntesis química.

## El suelo como sistema

```
PIRÁMIDE TRÓFICA DEL SUELO:
  PLANTAS (productores primarios)
    ↑ captan C como CO₂ · mineralizan N, P, K con ayuda de hongos
  MICORRIZA (asociación planta-hongo):
    → el hongo coloniza la raíz, amplía su superficie x10-x1000
    → la planta da azúcares al hongo; el hongo trae agua + P + micronutrientes
  BACTERIAS FIJADORAS DE N₂ (Rhizobium en leguminosas, Azospirillum en gramíneas):
    → convierten N₂ atmosférico en NH₄⁺ (nitrógeno disponible)
  FAUNA DEL SUELO (lombrices, colémbolos, ácaros, ciempiés):
    → fragmentan materia orgánica → superficie de ataque para bacterias x1000
  BACTERIAS Y HONGOS DESCOMPONEDORES (último nivel):
    → mineralizan la MO → N, P, S liberados en forma asimilable
```

## Principios de diseño

```
1. ALIMENTAR EL SUELO, no la planta directamente
   → la planta que necesita NPK foliar es síntoma de suelo muerto
   → MO bien descompuesta + microbioma activo = nutrición integrada

2. MÍNIMA LABRANZA (no-till preferente)
   → el laboreo destruye la red micelial → tarda 6-12 meses en reconstituirse
   → excepción: descompactación puntual con biosubsolador o aireador

3. COBERTURA VEGETAL PERMANENTE
   → el suelo desnudo pierde C, se erosiona, activa patógenos
   → cubiertas vegetales (trigo sarraceno, veza, centeno) o mulch (paja, chips madera)

4. DIVERSIDAD VEGETAL
   → rotaciones, asociaciones (tomate+albahaca+caléndula), policultivo
   → cada especie exuda compuestos distintos → diversidad microbiana

5. AGUA COMEDIDA
   → el exceso de riego lixivia N, mata microbioma aerobio, pudre raíces
   → riego por goteo al amanecer → mínima evaporación, máxima eficiencia
```

## Inputs y outputs naturales

```
INPUTS EXTERNOS JUSTIFICADOS:
  Compost maduro         → MO estable + microbioma · 5-10 cm/año en superficie
  Vermicompost           → hormonas vegetales (AIA) + microbioma de alta densidad
  Bokashi                → fermentación láctica → neutraliza patógenos → fácil
  Purín de ortiga        → N + Fe + silicio → vigor foliar
  Biol                   → NPK soluble + fitohormonas · dilución 1:10-1:20
  Algas (extracto Ascophyllum nodosum) → citocininas + betaínas · resistencia estrés
  Biochar                → esponja de C + microhábitat para microbioma · 1-3% del volumen de suelo
  Micorrizas (inoculante) → colonización de raíces nuevas en sustrato pobre/esterilizado
  Caliza / dolomita      → subir pH ácido (target 6.0-7.0 según cultivo)
  Azufre elemental       → bajar pH alcalino (oxidación → H₂SO₄) + antifúngico
  Roca fosfórica         → P de liberación lenta (requiere pH ácido + microbioma)

INPUTS NUNCA en agroecología:
  NPK mineral soluble de síntesis → mata microbioma osmóticamente
  Fungicidas sistémicos → eliminan micorrizas + microbioma del suelo
  Glifosato            → quelante de micronutrientes + disruptor del suelo
  Turba de pantano     → recurso no renovable (sustituir por coco + vermicompost)
```

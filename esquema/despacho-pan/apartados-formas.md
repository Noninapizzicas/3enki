# Apartados · Formas — silueta visual general de la web de consumo

> La "forma" que marca la web de este cliente: redondeado vs recto, denso vs aire, minimalista vs ornamentado.

## Silueta
- **Redondeado suave**: botones y tarjetas con esquinas redondeadas (amable, no agresivo).
- **Aire generoso**: espaciado amplio, sin saturar (diseño para mayores).
- **Minimalista pero cálido**: sin ornamentación innecesaria, pero con carácter artesanal (no frío).

## Forma de cada componente
- **Hero**: una pantalla limpia, titular grande, CTA claro.
- **Tarjetas**: redondeadas, con aire, icono + nombre + precio.
- **Selectores**: grandes, táctiles, sin campos de texto.
- **Botones de acción**: grandes, con etiqueta clara.
- **Estados de confirmación**: banner claro, verde, con la señal.

## Lo que la forma transmite
- **Accesible**: para mayores, sin fricción.
- **Cercano**: artesanal, no corporativo.
- **Confiable**: el camino mínimo, claro, sin sorpresas.

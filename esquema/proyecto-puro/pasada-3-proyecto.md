# Pasada 3 — Los recursos del proyecto

---

### 3.1 Personas

| Hueco | Respuesta |
|---|---|
| IDENTIDAD | La gente que hace el proyecto. Sus habilidades, su tiempo, su motivación. |
| RESTRICCIONES | No son infinitas. No son intercambiables. Necesitan comunicación, liderazgo, contexto. |
| CONTRATO | Con estas personas, en este tiempo, se produce el resultado. |
| NO-OBJETIVOS | No son recursos como el dinero. Tienen agencia propia. |
| PREGUNTAS ABIERTAS | ¿Cuántas personas hacen falta mínimamente para que sea un proyecto? |

**→ ATÓMICO**

### 3.2 Dinero

| Hueco | Respuesta |
|---|---|
| IDENTIDAD | El presupuesto. Lo que cuesta el proyecto. |
| RESTRICCIONES | Se acaba. Hay que justificarlo. |
| CONTRATO | Con este presupuesto se financia el proyecto hasta su entrega. |
| NO-OBJETIVOS | No es el valor del proyecto. El valor es lo que el proyecto genera. |
| PREGUNTAS ABIERTAS | ¿Quién pone el dinero y qué espera a cambio? |

**→ ATÓMICO**

### 3.3 Herramientas

| Hueco | Respuesta |
|---|---|
| IDENTIDAD | Todo lo que ayuda a hacer el proyecto: software, máquinas, metodologías, plantillas. |
| RESTRICCIONES | Las herramientas limitan o potencian lo que se puede hacer. |
| CONTRATO | Con estas herramientas se ejecuta el trabajo del proyecto. |
| NO-OBJETIVOS | Las herramientas no hacen el proyecto. Las personas lo hacen. |
| PREGUNTAS ABIERTAS | ¿Cuándo una herramienta condiciona el resultado? |

**→ ATÓMICO**

### 3.4 Conocimiento

| Hueco | Respuesta |
|---|---|
| IDENTIDAD | Lo que el equipo sabe y lo que necesita aprender. |
| RESTRICCIONES | No se sabe todo al empezar. Partes sabiendo algo y aprendes el resto. |
| CONTRATO | El conocimiento necesario para completar el proyecto se adquiere durante el proyecto. |
| NO-OBJETIVOS | No es la documentación. El conocimiento vivo está en las personas. |
| PREGUNTAS ABIERTAS | ¿Cuánto conocimiento previo es necesario para empezar? |

**→ ATÓMICO**

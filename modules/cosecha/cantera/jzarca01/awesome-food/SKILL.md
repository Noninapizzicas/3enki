# awesome-food — Lista curada de proyectos de comida en GitHub

Lista awesome (241+ estrellas) con APIs, datasets, librerías y herramientas open-source relacionadas con alimentación y cocina.

## Categorías principales

### APIs de comida

| API | Descripción |
|---|---|
| **Spoonacular** | API completa de recetas, nutrición, meal planning (freemium) |
| **Edamam** | Nutrición, búsqueda de recetas, análisis de ingredientes |
| **TheMealDB** | Base de datos de recetas gratuita con imágenes |
| **TheCocktailDB** | Base de datos de cócteles (mismo formato que TheMealDB) |
| **Open Food Facts API** | Datos nutricionales de productos (open data) |
| **USDA FoodData Central** | Base de datos nutricional del gobierno USA |
| **Tasty API** | Recetas de BuzzFeed Tasty (vía RapidAPI) |

### Datasets abiertos

| Dataset | Contenido |
|---|---|
| **RecipeNLG** | 2M+ recetas para NLP |
| **Food-101** | 101k imágenes de 101 tipos de comida (clasificación) |
| **Recipe1M+** | 1M recetas con imágenes (investigación) |
| **What's Cooking** | Dataset Kaggle de recetas por cocina/país |
| **Open Food Facts dump** | Base completa descargable (CSV/MongoDB) |

### Librerías y herramientas

| Proyecto | Lenguaje | Función |
|---|---|---|
| **recipe-scrapers** | Python | Scraping de recetas de 400+ sitios |
| **CookLang** | Rust | Lenguaje markup para recetas |
| **Mealie** | Python | Gestor de recetas self-hosted |
| **Tandoor** | Python | Gestor de recetas con meal planning |
| **grocy** | PHP | ERP doméstico con inventario |

## Valor para referencia

- Índice completo del ecosistema open-source de alimentación
- APIs clasificadas por tipo y modelo de acceso (gratis/freemium/pago)
- Datasets para machine learning culinario
- Punto de partida para explorar cualquier nicho food-tech

# Despensa mediterránea — los ingredientes comunes

Desde Gibraltar a Beirut, la despensa mediterránea comparte una base que une cocinas muy distintas. Estos ingredientes son el hilo conductor.

## Los 10 pilares

| Ingrediente | Función | Presente en |
|---|---|---|
| **Aceite de oliva** | Grasa de cocción + condimento + conserva | Todas |
| **Ajo** | Aromático base | Todas |
| **Tomate** | Base de salsas, ensaladas, guisos | Todas (post-1500) |
| **Cebolla** | Base aromática universal | Todas |
| **Limón/cítricos** | Ácido, frescura, marinada | Todas |
| **Pan/trigo** | Carbohidrato base — pasta, pan, cuscús, phyllo | Todas |
| **Legumbres** | Proteína + sustento | Todas — garbanzos, lentejas, fabes |
| **Hierbas frescas** | Sabor, aroma, identidad | Cada país sus favoritas |
| **Vino/vinagre** | Ácido, deglasar, beber | Francia, Italia, España, Grecia |
| **Queso de oveja/cabra** | Proteína, umami, textura | Feta, manchego, pecorino, roquefort |

## El tomate — el gran invasor (post-1492)

```
Llegó de América a Europa en el s. XVI.
Italia lo adoptó en el s. XVIII (salsa de tomate napolitana).
España lo integró en el gazpacho (s. XIX).
El Mediterráneo pre-tomate usaba agraz (uva verde) y granadas como ácido.

Hoy es impensable la cocina mediterránea sin tomate, 
pero tiene menos de 300 años de presencia.
```

|---|---|---|

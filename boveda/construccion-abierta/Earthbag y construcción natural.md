# Earthbag y construcción natural

Técnicas constructivas que usan tierra, arena, cal y fibras naturales — sin cemento Portland o con mínimo. Bajo coste, baja huella de carbono, auto-construcción.

## Técnicas principales

### Earthbag / Superadobe

Sacos de polipropileno rellenos de tierra compactada, apilados con alambre de espino entre hiladas.

| Aspecto | Detalle |
|---|---|
| **Inventor** | Nader Khalili (CalEarth Institute, 1984) |
| **Material** | Sacos de rafia + tierra local + alambre de espino |
| **Forma** | Domo (la más resistente), ábside, o muro recto |
| **Espesor muro** | 300–400 mm |
| **Resistencia** | Probado en zona sísmica (CalEarth, aprobado por ICC) |
| **Coste** | $5–$20/m² (muro bruto, sin acabados) |
| **Herramientas** | Pala, pisón, tijeras, alambre. Cero maquinaria |

#### Proceso constructivo

1. **Cimentación**: zanja con grava + primera hilada con mezcla tierra-cemento (10%)
2. **Hiladas**: llenar saco → colocar → apisonar → alambre de espino encima → repetir
3. **Dinteles**: arco con sacos (sin encofrado) o dintel de madera/acero
4. **Acabado**: revoco de cal-arena (exterior) o barro-paja (interior)
5. **Techo**: domo cerrado, o estructura de madera convencional sobre muros

### Cob (tierra-paja)

Mezcla plástica de arcilla + arena + paja larga, construida a mano capa por capa.

| Aspecto | Detalle |
|---|---|
| **Material** | Arcilla + arena gruesa + paja (proporción 1:2–3:fibra) |
| **Técnica** | Moldeo manual, sin encofrado ni moldes |
| **Espesor** | 400–600 mm (masividad = inercia térmica) |
| **Secado** | 1–3 semanas por hilada de 300 mm (clima dependiente) |
| **Coste** | $2–$10/m² (material esencialmente gratuito) |
| **Limitación** | Solo climas secos/templados. Lentísimo en húmedo |

### Adobe (bloques de barro)

| Aspecto | Detalle |
|---|---|
| **Bloque** | Arcilla + arena + paja, moldeado y secado al sol |
| **Tamaño típico** | 300×150×100 mm |
| **Producción** | 200–500 bloques/día (manual con molde) |
| **Resistencia** | 1–3 MPa (suficiente para 1–2 plantas) |
| **Ventaja vs cob** | Piezas uniformes, construcción más rápida, stockable |

### Tapial (rammed earth)

| Aspecto | Detalle |
|---|---|
| **Técnica** | Tierra húmeda apisonada dentro de encofrado |
| **Espesor** | 300–600 mm |
| **Resistencia** | 2–5 MPa (estabilizado con 5% cemento: hasta 10 MPa) |
| **Acabado** | El propio muro es el acabado (textura de capas compactadas) |
| **Coste** | $30–$80/m² (el encofrado es lo caro) |

## Consideraciones estructurales

- **Sismo**: earthbag domo y tapial estabilizado son los más resistentes. Cob y adobe requieren refuerzo (malla, contrafuertes)
- **Humedad**: todas las técnicas de tierra requieren protección contra agua — sobrecimiento de 300+ mm, alero generoso, drenaje perimetral
- **Normativa**: la mayoría de países no tienen código específico. CalEarth logró aprobación ICC para earthbag. Tapial tiene normativa en Australia (AS 3700), Nueva Zelanda (NZS 4298), y algunos estados de EE.UU.

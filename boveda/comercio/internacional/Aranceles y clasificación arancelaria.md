# Aranceles y clasificación arancelaria

## Código HS (Harmonized System)
Nomenclatura internacional de la Organización Mundial de Aduanas: asigna a cada mercancía un código
numérico de **6 a 10 dígitos**. Los primeros 6 son fijos y estandarizados globalmente; cada país
añade dígitos propios para desglosar estadística/arancel local. Usado por >200 países; clasifica
>98% del comercio internacional.

**Por qué importa**: el código HS es el dato que determina cuánto se paga en aranceles, IVA y otros
impuestos de importación — un código mal asignado genera sobrecoste o sanción.

```
Proceso: producto → código HS (6-10 dígitos) → tabla arancelaria del país destino → % arancel
                                              → + IVA/impuestos de importación → coste total en aduana
```

## 🔗 Lazos de unión
El arancel resultante se suma al coste antes de calcular el [[Márgenes y rotación|margen]]; el
[[Incoterms 2020|incoterm]] pactado decide quién lo paga y en qué punto de la cadena.

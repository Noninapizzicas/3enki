# Awesome Electronics — Referencia curada para ingenieros electrónicos

Lista curada principal de recursos para ingenieros electrónicos y hobbyistas. 6k+ estrellas en GitHub. Cubre desde aprendizaje hasta fabricación de PCBs.

|---|---|

| **Eagle** | De Autodesk, versión gratuita limitada. Amplio ecosistema de librerías |

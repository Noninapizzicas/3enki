# Paso 3 — Diseccionador sobre cada hueco de prisma

---

## H1 · IDENTIDAD

"Determinar qué es el producto y qué trabajo del cliente resuelve"

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | JUICIO — requiere entender el producto, su contexto, lo que el cliente necesita. No hay fórmula. |
| ¿Quién lo hace? | Quien conoce el producto y el cliente |
| ¿De a una o tanda? | De a una |
| ¿Qué falta? | Si no se entiende bien → se marca como pendiente |
| ¿Cambia de medio? | No |

**Forma: MECÁNICA_BLANDAS**

---

## H2 · RESTRICCIONES

"Identificar las reglas duras del producto (alérgenos, seguridad, caducidad)"

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | MECÁNICA_DURA — las restricciones son hechos. O las tiene o no. |
| ¿Quién lo hace? | Cualquier ejecutor con acceso a la ficha del producto |
| ¿De a una o tanda? | De a una |
| ¿Qué falta? | Si se desconoce una restricción obligatoria → se marca como pendiente (no se asume "no tiene") |
| ¿Cambia de medio? | No |

**Forma: MECÁNICA_DURA**

---

## H3 · CONTRATO

"Definir atributos, opciones y estados del producto"

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | MECÁNICA_BLANDAS — hay una plantilla (atributos, opciones, estados), pero decidir qué opciones aplica y cómo se comportan requiere conocer el producto. |
| ¿Quién lo hace? | Quien conoce el producto |
| ¿De a una o tanda? | De a una |
| ¿Qué falta? | Opciones no determinadas → se dejan vacías, no se inventan |
| ¿Cambia de medio? | No |

**Forma: MECÁNICA_BLANDAS**

---

## H4 · NO-OBJETIVOS

"Declarar qué NO es el producto"

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | MECÁNICA_BLANDAS — requiere entender el producto para saber lo que no es, pero una vez entendido, es declarativo. |
| ¿Quién lo hace? | Quien conoce el producto |
| ¿De a una o tanda? | De a una |
| ¿Qué falta? | Si no hay no-objetivos claros → se deja vacío (mejor que inventar) |
| ¿Cambia de medio? | No |

**Forma: MECÁNICA_BLANDAS**

---

## H5 · PREGUNTAS ABIERTAS

"Marcar lo privado o no computable del producto"

| Pregunta | Respuesta |
|---|---|
| ¿JUICIO o MECÁNICA? | MECÁNICA_DURA — lo privado se reconoce por su naturaleza (coste, stock, agenda, tarifa). Regla fija: si es privado del comerciante, se marca abierto. |
| ¿Quién lo hace? | Cualquier ejecutor |
| ¿De a una o tanda? | De a una |
| ¿Qué falta? | Si no hay preguntas abiertas → producto completo (madurez: listo) |
| ¿Cambia de medio? | No |

**Forma: MECÁNICA_DURA**

---

## Resumen

| Hueco | Forma | ¿Juicio? |
|---|---|---|
| IDENTIDAD | MECÁNICA_BLANDAS | Sí |
| RESTRICCIONES | MECÁNICA_DURA | No |
| CONTRATO | MECÁNICA_BLANDAS | Sí |
| NO-OBJETIVOS | MECÁNICA_BLANDAS | Sí |
| PREGUNTAS_ABIERTAS | MECÁNICA_DURA | No |

**3 MECÁNICA_BLANDAS, 2 MECÁNICA_DURA.**

Los huecos que requieren juicio son los que necesitan conocer el producto (IDENTIDAD, CONTRATO, NO-OBJETIVOS). Los mecánicos son los que siguen reglas fijas (RESTRICCIONES, PREGUNTAS_ABIERTAS).

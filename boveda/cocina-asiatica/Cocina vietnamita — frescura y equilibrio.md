# Cocina vietnamita — frescura y equilibrio

Vietnam es la cocina más fresca de Asia: hierbas crudas en cada plato, caldo transparente como espejo, texturas limpias. Influencia china en el norte, francesa en el sur.

## Principios

| Principio | Expresión |
|---|---|
| **Frescura** | Hierbas crudas en la mesa (menta, albahaca, cilantro, perilla) |
| **Contraste** | Cada plato tiene crujiente + blando, caliente + frío |
| **Ligereza** | Menos aceite que China, menos coco que Tailandia |
| **Equilibrio yin-yang** | Alimentos "fríos" y "calientes" se equilibran |
| **Dipping** | Cada plato tiene su salsa de acompañamiento |

## Pho — el plato nacional

```
Pho bò (ternera):
  Caldo: huesos de ternera (6-12h) + cebolla + jengibre (tatemados)
         + anís estrellado + canela + clavo + cardamomo + semilla cilantro
  Fideos: bánh phở (arroz, planos, frescos)
  Proteína: ternera en láminas crudas (se cocina en el caldo) + ternera cocida
  Mesa: brotes de soja, albahaca thai, chile, lima, hoisin, sriracha

  El caldo es CRISTALINO — el secreto es fuego bajo constante y espumar siempre.
  La cebolla y jengibre se tateman (queman sobre llama) antes de ir al caldo.
```

| Variante | Carne | Región |
|---|---|---|
| **Pho bò** | Ternera | Hanoi (original) |
| **Pho gà** | Pollo | Nacional |
| **Pho Hanoi** | Más austero, pocas hierbas | Norte |
| **Pho Saigon** | Más dulce, más hierbas | Sur |

## Platos fundamentales

| Plato | Tipo | Descripción |
|---|---|---|
| **Bánh mì** | Sándwich | Baguette (herencia francesa) + paté + encurtidos + cilantro + chile |
| **Gỏi cuốn** | Spring roll fresco | Papel de arroz + gambas + fideos + hierbas + cerdo |
| **Chả giò** | Spring roll frito | Relleno de cerdo + taro + setas |
| **Bún chả** | Fideos | Fideos de arroz + cerdo a la brasa + nước chấm |
| **Cơm tấm** | Arroz | Arroz roto + cerdo a la brasa + huevo + verduras |
| **Bún bò Huế** | Sopa | Fideos gruesos + ternera + picante (Huế) |
| **Bánh xèo** | Crepe | Crepe de arroz + cúrcuma + gambas + brotes |
| **Cà phê sữa đá** | Bebida | Café filtro vietnamita + leche condensada + hielo |

## Nước chấm — la salsa universal

```
Fish sauce (nước mắm)   : 3 cucharadas
Agua                     : 3 cucharadas
Azúcar                   : 2 cucharadas
Lima                     : zumo de 1 lima
Ajo                      : 1 diente picado fino
Chile                    : 1 bird's eye picado

Equilibrar: dulce-salado-ácido-picante (los 4)
Acompaña: spring rolls, bún chả, bánh xèo, casi todo
```

## Hierbas frescas — la identidad vietnamita

| Hierba | Vietnamita | Uso |
|---|---|---|
| **Menta** | Rau húng | Pho, spring rolls, ensaladas |
| **Albahaca tailandesa** | Rau quế | Pho, sofritos |
| **Cilantro** | Rau mùi | Universal |
| **Perilla** | Tía tô | Envolver carne, ensaladas |
| **Culantro** | Rau mùi tàu | Pho (más intenso que cilantro) |
| **Rau răm** | Vietnamese coriander | Ensaladas, huevos |
